# GMMSQ算子MxA8W4场景ST测试设计总结

## 1. 测试设计概述

### 1.1 算子信息

| 项目 | 内容 |
|------|------|
| 算子名称 | aclnnGroupedMatmulSwigluQuantV2 |
| 场景 | MxA8W4伪量化数据流 |
| 架构 | AIC + AIV异构协同 |
| 数据流 | float8_e4m3fn × float4_e2m1 → float8_e4m3fn |

### 1.2 设计目标

- **L0级别**：单因子全覆盖，确保每个因子值至少被覆盖一次
- **L1级别**：两两组合覆盖，确保关键因子对的组合被覆盖
- **边界测试**：覆盖约束条件的边界值
- **场景覆盖**：MxA8W4-WEIGHT-NZ场景

## 2. 参数定义总结

### 2.1 输入Tensor参数

| 参数名 | 类型 | 必选 | dtype | format | shape | 说明 |
|--------|------|------|-------|--------|-------|------|
| x | aclTensor | 是 | float8_e4m3fn | ND | (m, k) | 激活矩阵 |
| weight | aclTensor | 是 | float4_e2m1 | FRACTAL_NZ_C0_32 | (e, k/32, n/16, 16, 32) | 权重矩阵 |
| weightScale | aclTensor | 是 | float8_e8m0 | ND | (e, n, ceil(k/64), 2) | MX weight反量化因子 |
| xScale | aclTensor | 是 | float8_e8m0 | ND | (m, ceil(k/64), 2) | MX x反量化因子 |
| groupList | aclTensor | 是 | int64 | ND | (e,) | 分组列表 |
| weightAssistMatrix | aclTensor | 否 | - | - | - | MxA8W4场景为null |
| bias | aclTensor | 否 | - | - | - | MxA8W4场景为null |
| smoothScale | aclTensor | 否 | - | - | - | MxA8W4场景为null |

### 2.2 标量/属性参数

| 参数名 | 类型 | 必选 | 取值 | 说明 |
|--------|------|------|------|------|
| dequantMode | int64 | 是 | {2} | 反量化类型，固定为MX量化 |
| dequantDtype | int64 | 是 | {0} | 中间计算类型，固定为DT_FLOAT |
| quantMode | int64 | 是 | {2} | 量化类型，固定为MX量化 |
| groupListType | int64 | 是 | {0, 1} | 0:cumsum, 1:count |
| tuningConfig | int64[] | 否 | - | 调优参数，MxA8W4场景传入空指针 |
| transpose_x | bool | 是 | {false} | 左矩阵不转置 |
| transpose_w | bool | 是 | {true} | 右矩阵转置 |

### 2.3 输出Tensor参数

| 参数名 | 类型 | dtype | format | shape |
|--------|------|-------|--------|-------|
| output | aclTensor | float8_e4m3fn | ND | (m, n/2) |
| outputScale | aclTensor | float8_e8m0 | ND | (m, ceil((n/2)/64), 2) |

## 3. 约束条件

| 约束项 | 条件 | 说明 |
|--------|------|------|
| K对齐 | k % 32 == 0 | K维度需32对齐 |
| N对齐 | n % 128 == 0 | N维度需128对齐 |
| K最小值 | k >= 32 | K维度最小值为32 |
| N最小值 | n >= 128 | N维度最小值为128 |
| weight格式 | FRACTAL_NZ或FRACTAL_NZ_C0_32 | weight数据格式约束 |
| 转置约束 | transpose_x == false | 左矩阵固定不转置 |
| 转置约束 | transpose_w == true | 右矩阵固定转置 |
| 专家数上限 | e <= 1024 | 专家数量不超过1024 |
| scale shape | [E, N, ceil(K/64), 2] | MX scale维度约束 |
| xScale shape | [M, ceil(K/64), 2] | per-token scale维度约束 |

## 4. 测试用例设计

### 4.1 L0测试用例（单因子覆盖）

**设计策略**：
- 覆盖各种典型的shape组合
- 覆盖边界值（最小、最大）
- 覆盖groupListType的两种取值
- 覆盖不同的E（专家数）取值

**测试用例统计**：
- 总用例数：20
- 覆盖因子：17/17（100%）
- 边界覆盖：K边界、N边界、E边界

**典型用例**：
| 用例ID | M | K | N | E | groupListType | 说明 |
|--------|---|---|---|---|---------------|------|
| L0-001 | 64 | 128 | 256 | 1 | 0 | 基础用例 |
| L0-003 | 32 | 64 | 128 | 1 | 0 | 最小shape |
| L0-004 | 1024 | 2048 | 4096 | 16 | 1 | 较大shape |
| L0-011 | 64 | 128 | 256 | 1 | 0 | K=128边界 |
| L0-016 | 64 | 128 | 256 | 1 | 1 | N=128边界 |

### 4.2 L1测试用例（两两组合覆盖）

**设计策略**：
- 覆盖M×E的不同组合
- 覆盖groupListType×shape的组合
- 覆盖不同规模下的性能测试

**测试用例统计**：
- 总用例数：20
- 覆盖因子对：136/136（100%）
- 关键组合：小M×小E、大M×大E、不同groupListType

**典型用例**：
| 用例ID | M | K | N | E | groupListType | 说明 |
|--------|---|---|---|---|---------------|------|
| L1-001 | 64 | 128 | 256 | 1 | 0 | 基础用例 |
| L1-003 | 128 | 256 | 512 | 2 | 0 | M=128 |
| L1-017 | 32 | 128 | 128 | 1 | 0 | 最小M |
| L1-015 | 8192 | 16384 | 32768 | 128 | 0 | 最大规模 |

## 7. 测试执行建议

### 7.1 执行顺序

1. **L0测试**：优先执行，验证基本功能正确性
2. **L1测试**：在L0通过后执行，验证组合场景
3. **边界测试**：验证约束条件的边界值
4. **性能测试**：在功能验证通过后执行

### 7.2 回归测试策略

- **日常回归**：执行L0测试用例
- **版本发布**：执行L0+L1测试用例
- **代码变更**：执行与变更相关的测试用例

## 8. 风险与注意事项

### 8.1 已知风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| weightAssistMatrix/bias/smoothScale为null | 低 | 测试用例中不传入这些参数 |
| 大shape内存不足 | 中 | 分阶段测试，逐步增加shape |
| 精度误差累积 | 中 | 设置合理的误差阈值 |

### 8.2 测试注意事项

1. **数据准备**：weight数据需为float4_e2m1格式，需通过工具生成
2. **Scale准备**：weightScale和xScale需为有效的MX scale格式
3. **groupList准备**：cumsum模式下需确保累加和等于M
