--- opkernel 编译错误 ---
1. engram_fetch.h:11 - fatal error: 'adv_api/hcomm/hcomm.h' file not found
   原因: 当前 CANN 9.0.0 安装包不包含此头文件 (hcomm.h 在整个安装目录不存在)
   需要: 更新 CANN 包版本, 或确认 adv_api/hcomm 在 kernel 编译 include path 中
   adv_api/hccl/hccl.h 同样可能缺失

--- 第二轮 API 变更 ---
1. aclnn API: 删除 numRanks/hcclBufferSize 参数, 新增 hiddenSize(int32_t), fetched 移到 indices 后面
   新签名: aclnnEngramFetchGetWorkspaceSize(bufferhandle, indices, fetched, hiddenSize, numEntriesPerRank, outputDtype, workspaceSize, executor)
2. def.cpp: 删除 num_ranks/hccl_buffer_size attr, 新增 hidden_size REQUIRED Int attr
3. EngramBufferHandle: 新增 rankSize 字段, kernel 从 bhPtr_->rankSize 读 numRanks
4. EngramFetchInfo: 删除 numRanks/hcclBufferSize 字段
5. infershape: output dim(1) 从 hidden_size attr 取 (而非 numEntriesPerRank)
6. tiling: hiddenDim 直接从 hidden_size attr 读, 不再从 output shape 推算
7. kernel: numRanks_ = bhPtr_->rankSize, Process 按 rank stride 分核 (rank = aivId_; rank < numRanks_; rank += aivNum_)
8. binary.json: attrs 列表更新
