# QAR/QRS 算子性能指标体系

> 基于 2026-05-13/14 实测数据（2/4/8 卡，int8），统一线性模型，R² > 0.99

---

## 1. 指标定义

```
V_data  = 每 rank 有效载荷
          QAR: bs × h × 1B
          QRS: bs × h / world_size × 1B

BW      = V_data / T_kernel      (GB/s)
Util    = BW / 56 GB/s × 100%
```

---

## 2. 统一数学模型

Kernel 时间建模为：

```
T(V, N, op) =  T_base(N, op)  +  V / BW_eff(N, op)
               └─固定开销─┘     └──每 MB 时间成本──┘
```

其中：
- `T_base` = ReadStatus 软同步 + kernel 启动开销，随卡数 N 线性增长
- `BW_eff` = 等效带宽，包含 MTE 搬运 + 反量化计算 + 流水线开销

### 2.1 QAR

```
T_base(N)  = -3.0 + 2.9 × N          (us)
slope(N)   = 35.6 + 0.4 × N          (us/MB)

T(V, N) = (-3.0 + 2.9N) + V × (35.6 + 0.4N) / 1000
```

| N | T_base | slope | BW_eff | Util_max |
|---|--------|-------|--------|----------|
| 2 | 2.8 us | 36.4 us/MB | 27.5 GB/s | 49.0% |
| 4 | 8.7 us | 37.2 us/MB | 26.8 GB/s | 47.9% |
| 8 | 20.4 us | 38.9 us/MB | 25.7 GB/s | 45.9% |

**特征**：slope 几乎不随 N 变化（0.4 us/MB/rank），CopyDataToWin 只写自己 Win 区，无放大。

### 2.2 QRS

```
T_base(N)  = 1.9 + 1.2 × N          (us)
slope(N)   = 32.1 + 1.7 × N          (us/MB)

T(V, N) = (1.9 + 1.2N) + V × (32.1 + 1.7N) / 1000

额外惩罚（仅 N ≥ 8 且 V > V_crit ≈ 6 MB）：
T += 14.1 × (V - 6) / 1000           (us)
```

| N | T_base | slope | BW_eff | Util_max |
|---|--------|-------|--------|----------|
| 2 | 4.2 us | 35.4 us/MB | 28.2 GB/s | 50.4% |
| 4 | 6.6 us | 38.7 us/MB | 25.8 GB/s | 46.1% |
| 8 (V≤6) | 11.3 us | 45.4 us/MB | 22.0 GB/s | 39.4% |
| 8 (V>6) | — | 59.5 us/MB | 17.0 GB/s | 30.3% |

**特征**：slope 随 N 线性增长（1.7 us/MB/rank，是 QAR 的 4×）。N=8 大 V 时额外 +14.1 us/MB（all2all MTE 写带宽饱和）。

### 2.3 QAR vs QRS 斜率差异的物理根源

同一份 `mte_comm.h`，两种算子走不同分支：

```cpp
// mte_comm.h CopyDataToWin()
if constexpr (isReduceScatter) {
    // === QRS 路径 ===
    for (curRank = 0; curRank < rankDim; ++curRank) {
        CopyDataBlock(offset + curRank * slice, ...);  // 写到第 curRank 个 Win 区
    }
} else {
    // === QAR 路径 ===
    CopyDataBlock(offset, ...);  // 只写自己 Win 区
}
```

**写入量对比**：

```
QAR:  每 rank 写 自己 Win 区 × 1    →  V_data 写入
QRS:  每 rank 写 所有 N 个 Win 区    →  V_data × N 写入（all2all 放大）
```

N=8、V=12 MB 时：QAR 写 12 MB，QRS 写 **96 MB**。QRS slope 随 N 的增长（1.7 us/MB/rank）正是 all2all 放大的线性体现。到 N=8 大 V 时 MTE 写带宽饱和，额外惩罚 +14.1 us/MB。

## 3. 判定标准

```
T_actual ≤ T_expected(V, N) × 1.10   →  PASS
T_actual  > T_expected(V, N) × 1.10   →  FAIL（性能退化 > 10%）
```

其中 `T_expected` 按上节公式计算：

```
QAR:  T_exp = (-3.0 + 2.9N) + V × (35.6 + 0.4N) / 1000
QRS:  T_exp = (1.9 + 1.2N) + V × (32.1 + 1.7N) / 1000
      + 14.1 × max(0, V - 6) / 1000    [仅 N ≥ 8]
```

### 3.2 使用示例

新增 shape `[64, 7168]`，world_size=4，QAR：

```
V = 64 × 7168 / 1024² = 0.438 MB

T_expected = (-3.0 + 2.9×4) + 0.438 × (35.6 + 0.4×4)
           = 8.6 + 0.438 × 37.2 = 8.6 + 16.3 = 24.9 us

实测 T_actual = 25.1 us
判定: 25.1 / 24.9 = 1.008 < 1.10  →  PASS ✓
```
