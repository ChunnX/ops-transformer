# QAR 算子性能指标会议纪要

**时间**：2026-05-14  
**与会人**：余昉、缪铭浩、吴可歆、熊一夫

---

## 结论

### 1. 废弃旧指标：与小算子级联对比

QAR 算子此前采用与小算子级联对比的性能指标，要求达到 1.4 倍性能收益。经讨论认为该指标不合理：

- QAR 走 MTE 通路（当前实现为 one-shot 模式），小算子级联走 CCU/AICPU 通路，二者基于不同的硬件引擎，带宽特性有本质差异，直接对比没有意义。

**结论**：废弃该指标。

### 2. 新指标：与理论时间对比

新的性能判定方式为：实测 kernel 时间与理论计算时间对比，要求不超过理论时间的 1.1 倍即为合格。

理论时间公式：

```
T_budget(V, N) = (5 + 2N) + V × N / (56 × log₂N)
```

其中 V 为有效载荷（MB），N 为卡数，56 GB/s 为 MTE 单口峰值带宽，log₂N 为流水线等效深度。

判定规则：

```
T_actual ≤ T_budget(V, N) × 1.10  →  合格
T_actual  > T_budget(V, N) × 1.10  →  不合格
```

详细标准见 `QAR_PERFORMANCE_STANDARD.md`。

**结论**：采纳该指标作为 QAR 算子性能验收标准。

### 3. QAR 算子定位

QAR 算子在整网中不存在，其定位为 **DEBUG 算子**，主要用于测算 MatmulAllReduce 算子的通算掩盖率（compute-communication overlap ratio），作为性能分析的辅助工具。
