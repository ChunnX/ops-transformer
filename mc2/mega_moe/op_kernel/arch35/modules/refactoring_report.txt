一、原始结构
  单一文件 mega_moe.h (1376行):
    - class MegaMoe 包含所有逻辑 (Init + Process 及全部私有方法)
    - 多核分发与单核计算混合在同一类方法中
    - blockIdx_/aivCoreIdx_/subBlockIdx_/blockNum_/blockAivNum_ 等全局索引
      直接作为类成员变量，在各方法内部隐式使用

三、核心变换规则
  ───────────────────────────────────────────────────────────────────

  1) blockIdx 替换为 TileInfo 显式参数:

     原始:
       uint32_t blockIdx_ = GetBlockIdx() / GetTaskRation();    // 类成员
       uint32_t aivCoreIdx_ = GetBlockIdx();                    // 类成员
       uint32_t subBlockIdx_ = GetSubBlockIdx();                // 类成员
       uint32_t blockNum_ = GetBlockNum();                      // 类成员
       uint32_t blockAivNum_ = GetBlockNum() * 2;               // 类成员

     新:
       struct TileInfo {
           uint32_t tileIdx;       // ← blockIdx_  (AIC核索引)
           uint32_t totalTiles;    // ← blockNum_  (AIC核总数)
           uint32_t aivTileIdx;    // ← aivCoreIdx_ (AIV核索引)
           uint32_t aivTotalTiles; // ← blockAivNum_ (AIV核总数)
           uint32_t subTileIdx;    // ← subBlockIdx_ (子块索引0/1)
       };
       // 在 mega_moe.h Process() 中一次性计算:
       tile_.tileIdx     = blockIdx_;
       tile_.totalTiles  = blockNum_;
       tile_.aivTileIdx  = aivCoreIdx_;
       tile_.aivTotalTiles = blockAivNum_;
       tile_.subTileIdx  = subBlockIdx_;

  2) 循环分核替换:

     原始:
       for (int32_t curExpertId = aivCoreIdx_; curExpertId < totalExperts;
            curExpertId += blockAivNum_, ++iter)
     新:
       for (int32_t curExpertId = tile.aivTileIdx; curExpertId < totalExperts;
            curExpertId += tile.aivTotalTiles, ++iter)

  3) TilingByCore → TilingByTile:

     原始:
       TilingByCore(totalLen, coreLen, coreOffset, align);
       // 内部使用 GetBlockIdx()/GetBlockNum()
     新:
       TilingByTile(totalLen, tileLen, tileOffset, tile.aivTileIdx, tile.aivTotalTiles, align);
       // 显式传入 tileIdx/totalTiles, 不使用硬件API

  4) 类成员变量 → 模块State结构体:

     原始:
       class MegaMoe { ... uint32_t maskSlotSize_; LocalTensor<...> tensor_; ... };
     新:
       struct TopKGatherState { ... uint32_t maskSlotSize; LocalTensor<...> tensor; ... };
       // 各模块独立State, mega_moe.h负责组装与传递

  5) AtomicAdd flag中的 blockIdx_ → tile.tileIdx:

     原始:
       ... + static_cast<uint64_t>(blockIdx_) * INT_CACHELINE;
     新:
       ... + static_cast<uint64_t>(tile.tileIdx) * INT_CACHELINE;

  6) expertRevNumsGlobalTensor偏移中 blockIdx_ → tile.tileIdx:

     原始:
       expertRevNumsGlobalTensor_[localExpertId * INT32_PER_256B * aicNum_ + INT32_PER_256B * blockIdx_]
     新:
       expertRevNumsGlobalTensor_[localExpertId * INT32_PER_256B * state.aicNum + INT32_PER_256B * tile.tileIdx]

  7) subBlockIdx_ 判断 → tile.subTileIdx:

     原始:
       if (subBlockIdx_ == 1) { ... }
       if (GetSubBlockIdx() != 0) { ... }
     新:
       if (tile.subTileIdx == 1) { ... }
       if (tile.subTileIdx != 0) { ... }
