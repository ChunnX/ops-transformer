时间戳边界：同一 AI Block 内的 AIC、AIV0、AIV1 使用同一时钟并可直接对齐；不同 AI Block 可能存在固定偏移，因此每组单独归零，禁止从不同组的横向位置推断绝对先后或 handoff 间隔。
细粒度边界：GMM1/GMM2/SwiGLU 按本卡 routed expert index 展开，设备记录长度由 header 中的专家数动态决定；未参与该专家的物理核保留空槽，wave 归属由已校验的运行时分组规则推导。橙色只连接同一 wave 的相邻专家：它由前一专家 end 与后一专家 causal begin 推断，包含流水尾部、真实依赖等待和少量 Scalar 调度，不能解释为纯等待指令耗时。GMM1 专家 end 是低扰动 issue 边界，采用半透明虚线。
