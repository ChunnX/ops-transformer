# AlltoAllvQuantGroupedMatMul 性能优化方案

## 一、核心思想

### 1.1 多轮次通信调度

**总轮次**：基于全局最大接收量计算
```
totalRound = ceil(maxRecvSum / globalBaseA)  // globalBaseA固定2048
```

**每张卡每轮接收量**：基于本卡总接收量
```
localBaseA = ceil(本卡总接收量 / totalRound)
```

**通信调度策略**：按卡号顺序轮流通信
```
轮次调度表（以4卡为例）：
第0轮：所有卡从卡0接收数据
第1轮：所有卡从卡1接收数据
第2轮：所有卡从卡2接收数据
第3轮：所有卡从卡3接收数据
第4轮：所有卡从卡0接收数据（循环）
...
```

### 1.2 预通信阶段

**目的**：交换所有卡的 recvCnt 数组，计算全局参数

```
预通信 AlltoAllV：
- 每卡发送：本卡的 recvCnt 数组（长度 e * epWorldSize）
- 每卡接收：所有卡的 recvCnt 数组

计算结果：
- maxRecvSum = 所有卡中最大的总接收量
- totalRound = ceil(maxRecvSum / 2048)
- localBaseA[本卡] = ceil(本卡总接收量 / totalRound)
```

### 1.3 数据布局

**通信前（xGM）**：按专家排列
```
[专家0数据 | 专家1数据 | 专家2数据]
```

**通信后（recvBuffer）**：按发送卡和轮次排列
```
[轮0卡0数据 | 轮1卡1数据 | 轮2卡2数据 | ...]
每段内：[专家0片段 | 专家1片段 | ...]
```

## 二、地址偏移计算

### 2.1 A矩阵（xGM，通信输出）

**来源**：recvBuffer，累积各轮接收

**偏移计算**：
```
xOffset[第N轮] = 前N轮接收总量 * CeilDiv(H1, PACK_FACTOR)
```

### 2.2 B矩阵（wGM，权重）

**偏移计算**：
```
wOffset[专家M] = M * H1 * N1
```

### 2.3 C矩阵（yGM，输出）

**偏移计算**：
```
yOffset[第N轮] = 前N轮输出总量 * N1
```

### 2.4 Workspace布局

```
workspace基址
├── recvBuffer        (通信输出，A矩阵输入)
├── scaleCommOut      (MX场景Scale通信输出)
├── preCommBuffer     (预通信recvCount交换)
│   ├── sendBuffer    (epWorldSize * e * epWorldSize * sizeof(uint64_t))
│   └── recvBuffer    (epWorldSize * e * epWorldSize * sizeof(uint64_t))
├── groupList         (GMM groupNum参数)
└── ptrTable          (GetTensorAddr指针表)
```

## 三、通信量计算

### 3.1 本轮发送卡

**调度逻辑**：
```
srcRank[第N轮] = N % epWorldSize  // 按轮次循环选择发送卡
```

### 3.2 发送量（发送卡视角）

```
发送卡srcRank在本轮：
    发送量[dstRank] = Σ(每个专家本轮接收需求) * axis
    
    其中：本轮接收需求 = min(localBaseA[dstRank], 总需求 - 已接收)
```

### 3.3 接收量（接收卡视角）

```
接收卡dstRank在本轮从srcRank接收：
    接收量[srcRank] = min(localBaseA[dstRank], 从srcRank总需求 - 已从srcRank接收)
```

### 3.4 偏移量

```
发送偏移[第N轮] = 前N轮向目标卡已发送总量
接收偏移[第N轮] = 前N轮已接收总量
```

## 四、计算层

### 4.1 ProcessAll 逻辑

**核心**：本轮处理所有专家的本轮数据

```
对于每个专家：
    curRoundTokens = min(localBaseA, 总tokens - 已处理)
    groupList[专家] = cumulativeM
    cOffsetList[专家] = 输出偏移
    
调用 GMM Process（所有专家一次处理）
```

## 五、Scheduler流程

```
1. InitPreComm()    // 发送本卡recvCnt数组
2. WaitPreComm()    // 等待并计算 baseA, totalRound

3. 批次循环：
   for batchIdx in range(batchCount):
       轮次循环：
       for roundIdx in range(startRound, endRound):
           srcRank = roundIdx % epWorldSize
           
           if 本卡是发送卡(srcRank == rankId):
               LaunchSend(roundIdx)      // 发送数据
           
           if 本卡需要从srcRank接收:
               LaunchRecv(roundIdx)      // 接收数据
           
           WaitSend/Recv(roundIdx)
           SyncAll()
           ProcessAll(roundIdx, localBaseA)

4. End()
```

## 六、4卡举例

### 6.1 数据设定

| 卡 | 总发送 | 总接收 | localBaseA |
|----|--------|--------|------------|
| 0卡 | 240 | 180 | 180/12=15 |
| 1卡 | 300 | 240 | 240/12=20 |
| 2卡 | 180 | **360** | 360/12=30 |
| 3卡 | 300 | 180 | 180/12=15 |

**globalBaseA** = 2048，**totalRound** = ceil(360/2048) 轮

### 6.2 轮次调度

```
第0轮：卡0发送，其他卡从卡0接收
第1轮：卡1发送，其他卡从卡1接收
第2轮：卡2发送，其他卡从卡2接收
第3轮：卡3发送，其他卡从卡3接收
第4轮：卡0发送（循环）...
```

### 6.3 第0轮通信量

**卡0发送**：
```
卡0→卡1：发送 min(20, 240) = 20 tokens
卡0→卡2：发送 min(30, 360) = 30 tokens  
卡0→卡3：发送 min(15, 180) = 15 tokens
```

**接收**：
```
卡1从卡0接收：20 tokens
卡2从卡0接收：30 tokens
卡3从卡0接收：15 tokens
```
