# AlltoAllvQuantGroupedMatMul 性能优化方案

## 一、核心思想

### 1.1 多轮次通信调度

**总轮次**：基于全局最大接收量计算
```
totalRound = ceil(maxRecvSum / globalBaseA)  // globalBaseA默认2048
约束：totalRound ≤ 63（TT场景）或 ≤ 31（MX场景）
```

**每张卡每轮接收量**：基于本卡总接收量
```
baseAPerRank[rankIdx] = ceil(recvSumPerRank[rankIdx] / totalRound)
localBaseA = baseAPerRank[本卡]
```

**关键改进**：每张卡维护所有卡的baseA和接收进度
- 存储每张卡的recvSum、baseA、接收进度（expertIdx、offset）
- 发送侧按目标卡的接收进度计算发送量，保证AlltoAllV语义配对

### 1.2 预通信阶段

**目的**：交换所有卡的 recvCnt 数组，计算全局参数

```
预通信 AlltoAllV：
- 每卡发送：本卡的 recvCnt 数组（长度 e * epWorldSize）
- 每卡接收：所有卡的 recvCnt 数组（存储在 preCommRecvGlobalBuffer_）

计算结果：
- recvSumPerRank[rankIdx] = 各卡总接收量
- maxRecvSum = 最大接收量（按rankId优先选择）
- totalRound = ceil(maxRecvSum / globalBaseA)
- baseAPerRank[rankIdx] = ceil(recvSumPerRank[rankIdx] / totalRound)
```

### 1.3 数据布局

**recvCounts_数组**：按expert索引顺序，存储本卡从各srcRank接收的数据量
```
布局: [srcRank0_expert0, srcRank0_expert1, srcRank1_expert0, srcRank1_expert1, ...]
计算: recvCounts_[srcRank * e_ + expertIdx]
```

**preCommRecvGlobalBuffer_**：预通信后，存储所有rank的recvCounts
```
布局: [rank0_recvCounts[0..e_*ep-1], rank1_recvCounts[0..e_*ep-1], ...]
索引: preCommRecvGlobalBuffer_[dstRank * e_ * epWorldSize_ + expertIdx]
```

## 二、方案A：发送侧按目标卡进度计算

### 2.1 核心思想

每张卡维护所有卡的接收进度：
- `recvSumPerRank_[MAX_EP_RANK_SIZE]`：每张卡的接收总量
- `baseAPerRank_[MAX_EP_RANK_SIZE]`：每张卡的baseA
- `recvProgressExpertIdx_[MAX_EP_RANK_SIZE]`：每张卡的expert进度
- `recvProgressExpertOffset_[MAX_EP_RANK_SIZE]`：每张卡的expert内偏移

发送时模拟目标卡的接收过程，计算本rank发给目标rank的数据量。

### 2.2 接收侧逻辑（本rank）

每轮从本rank的recvCounts_累加到localBaseA：

```cpp
while (accumulated < localBaseA_ && progressExpertIdx_ < e_ * epWorldSize_) {
    remaining = recvCounts_[progressExpertIdx_] - progressExpertOffset_;
    toAdd = Mc2Min(remaining, localBaseA_ - accumulated);
    
    srcRank = progressExpertIdx_ / e_;
    alltoAllvRecvCnt[srcRank] += toAdd;
    
    accumulated += toAdd;
    更新进度...
}
```

### 2.3 发送侧逻辑（按目标卡进度）

每轮计算发给每个dstRank的数据量：

```cpp
for (dstRank = 0; dstRank < rankDim_; dstRank++) {
    dstExpertIdx = recvProgressExpertIdx_[dstRank];
    dstOffset = recvProgressExpertOffset_[dstRank];
    sendAmount = 0;
    
    while (dstAccumulated < baseAPerRank_[dstRank] && dstExpertIdx < e_ * epWorldSize_) {
        dstRecvCntValue = preCommRecvGlobalBuffer_[dstRank * e_ * ep + dstExpertIdx];
        remaining = dstRecvCntValue - dstOffset;
        toAdd = Mc2Min(remaining, baseAPerRank_[dstRank] - dstAccumulated);
        
        srcRankOfExpert = dstExpertIdx / e_;
        if (srcRankOfExpert == rankId_) {
            sendAmount += toAdd;  // dstRank本轮从本rank接收的数据
        }
        
        dstAccumulated += toAdd;
        dstOffset += toAdd;
        if (dstOffset >= dstRecvCntValue) {
            dstExpertIdx++;
            dstOffset = 0;
        }
    }
    
    recvProgressExpertIdx_[dstRank] = dstExpertIdx;
    recvProgressExpertOffset_[dstRank] = dstOffset;
    alltoAllvSendCnt[dstRank] = sendAmount * axis;
}
```

### 2.4 AlltoAllV语义验证

**配对条件**：
```
本rank发给dstRank的数据 = dstRank本轮从本rank接收的数据
即：本rank.alltoAllvSendCnt[dstRank] == dstRank.alltoAllvRecvCnt[本rank]
```

**验证示例**：
- rank0 Round0 接收：recvCnt[1] = 19（从rank1接收19）
- rank1 Round0 发送给rank0：sendCnt[0] = ?
  - rank1发送侧模拟rank0的接收进度
  - rank0的recvCounts_[rank1*e_+...] 对应rank1发送给rank0的数据
  - rank1发送侧计算出sendCnt[0] = 19（配对成功）

## 三、4卡2专家完整示例

### 3.1 场景参数

- `e_ = 2, epWorldSize_ = 4, rankDim_ = 4`
- 本rank (rank0) 的 `recvCounts_ = [10, 20, 15, 25, 30, 5, 12, 28]`
  - 含义：从rank0专家0接收10，从rank0专家1接收20，从rank1专家0接收15，...
- 预通信后获得所有rank的recvCounts：
  - rank0: recvSum=145
  - rank1: recvSum=150（最大）
  - rank2: recvSum=140
  - rank3: recvSum=130
- `totalRound = 3, globalBaseA = 50`
- 各卡baseA：
  - baseAPerRank_[0] = ceil(145/3) = 49
  - baseAPerRank_[1] = ceil(150/3) = 50
  - baseAPerRank_[2] = ceil(140/3) = 47
  - baseAPerRank_[3] = ceil(130/3) = 44

### 3.2 Round 0 计算（rank0视角）

**接收侧（本rank）**：
```
进度: progressExpertIdx_=0, progressExpertOffset_=0, localBaseA_=49

累加过程：
idx=0: recvCounts_[0]=10, srcRank=0
  → alltoAllvRecvCnt[0] += 10
  → accumulated=10, progressExpertIdx_=1

idx=1: recvCounts_[1]=20, srcRank=0
  → alltoAllvRecvCnt[0] += 20
  → accumulated=30, progressExpertIdx_=2

idx=2: recvCounts_[2]=15, srcRank=1
  → alltoAllvRecvCnt[1] += 15
  → accumulated=45, progressExpertIdx_=3

idx=3: recvCounts_[3]=25, srcRank=1
  → 取4个凑到49
  → alltoAllvRecvCnt[1] += 4
  → accumulated=49, 停止
  → progressExpertIdx_=3, progressExpertOffset_=4

结果：alltoAllvRecvCnt = [30, 19, 0, 0]
```

**发送侧（发给dstRank=1）**：
```
模拟rank1的接收进度：
dstRank=1, baseAPerRank_[1]=50
dstExpertIdx=recvProgressExpertIdx_[1]=0
dstOffset=recvProgressExpertOffset_[1]=0

假设rank1_recvCounts_ = [20, 15, ...]
  idx=0: recvCnt=20, srcRank=0
    → srcRankOfExpert=0, 本rank(rank0)==srcRank
    → sendAmount += 20
    → dstAccumulated=20
  idx=1: recvCnt=15, srcRank=0
    → srcRankOfExpert=0, 本rank(rank0)==srcRank
    → sendAmount += 15
    → dstAccumulated=35
  idx=2: recvCnt=?, srcRank=1
    → srcRankOfExpert=1 != rankId_(0), 不累加sendAmount
  
结果：alltoAllvSendCnt[1] = sendAmount * axis
```

## 四、地址偏移计算

### 4.1 A矩阵（xGM，通信输出）

**来源**：recvBuffer，累积各轮接收

**偏移计算**：
```
xOffset[第N轮] = 前N轮接收总量 * CeilDiv(H1, PACK_FACTOR)
```

### 4.2 B矩阵（wGM，权重）

**偏移计算**：
```
wOffset[专家M] = M * H1 * N1
```

### 4.3 C矩阵（yGM，输出）

**偏移计算**：
```
yOffset[第N轮] = 前N轮输出总量 * N1
```

### 4.4 Workspace布局

```
workspace基址
├── recvBuffer        (通信输出，A矩阵输入)
├── scaleCommOut      (MX场景Scale通信输出)
├── preCommBuffer     (预通信recvCount交换)
│   ├── sendBuffer    (epWorldSize * e * epWorldSize * sizeof(uint64_t))
│   └── recvBuffer    (epWorldSize * e * epWorldSize * sizeof(uint64_t))
├── groupList         (GMM groupNum参数)
└── ptrTable          (GetTensorAddr指针表)
```

## 五、Scheduler流程

```
1. InitPreComm()    // 发送本卡recvCnt数组
2. localComputeOp.Process()  // MM计算（与预通信并行）
3. SyncAll()        // 等待MM计算完成
4. WaitPreComm()    // 等待预通信，计算baseA, totalRound

5. 轮次循环：
   for roundIdx in range(totalRound):
       LaunchCommMultiRound(roundIdx)  // 发起通信
       WaitMultiRound(roundIdx)        // 等待通信完成
       SyncAll()
       ProcessAll(roundIdx, localBaseA)

6. End()
```

## 七、最新修复与调试说明

### 7.1 Offset溢出问题修复

**问题根因**：
```
progressExpertOffset_ 成员变量跨轮未清零
第0轮结束：offset=1792
第1轮开始：expert全局路由=1808，remaining=1808-1792=16（正常）
第1轮继续：expert全局路由=1780，remaining=1780-1792=-12（负数！）
负数转uint64_t溢出：recvCnt变成超大值
```

**修复方案**：
使用本地变量代替成员变量：
```cpp
int32_t remaining = static_cast<int32_t>(globalRecvCnt);  // 每轮从0开始
int32_t toAdd = Mc2Min(remaining, localBaseA - recvAccumulated);
```

### 7.2 接收侧精确逻辑

**输入**：本rank的expert范围 `[rankId*e, rankId*e+e-1]`

**计算流程**：
```cpp
for (recvLoop = 0; recvLoop < e && recvAccumulated < localBaseA; recvLoop++) {
    currExpertIdx = rankId * e + recvLoop;
    
    // 获取所有srcRank路由到本expert的总数量
    globalRecvCnt = 0;
    for (srcRank = 0; srcRank < epWorldSize; srcRank++) {
        globalRecvCnt += preCommRecvGlobalBuffer[srcRank * e * ep + currExpertIdx];
    }
    
    // 本轮从本expert接收的数量
    remaining = globalRecvCnt;
    toAdd = Mc2Min(remaining, localBaseA - recvAccumulated);
    
    recvAccumulated += toAdd;
    
    // 按srcRank路由比例分配recvCnt[srcRank]
    for (srcRank = 0; srcRank < epWorldSize; srcRank++) {
        srcRankRecvCnt = preCommRecvGlobalBuffer[srcRank * e * ep + currExpertIdx];
        srcRankToAdd = (srcRankRecvCnt * toAdd) / globalRecvCnt;
        alltoAllvRecvCnt[srcRank] += srcRankToAdd * axis;
    }
}
```

### 7.3 发送侧精确逻辑

**输入**：本rank路由到的所有expert（recvCounts_数组）

**计算流程**：
```cpp
for (dstRank = 0; dstRank < rankDim; dstRank++) {
    dstExpertIdx = recvProgressExpertIdx[dstRank];
    dstOffset = recvProgressExpertOffset[dstRank];
    sendAmount = 0;
    
    for (sendLoop = 0; sendLoop < sendExpertNum && dstAccumulated < baseAPerRank[dstRank]; sendLoop++) {
        currExpertIdx = dstExpertIdx;
        myRecvCntValue = recvCounts_[currExpertIdx];  // 本rank路由到expert的数量
        remaining = myRecvCntValue - dstOffset;
        toAdd = Mc2Min(remaining, baseAPerRank[dstRank] - dstAccumulated);
        
        // expert归属判断
        dstRankOfExpert = currExpertIdx / e;
        if (dstRankOfExpert == dstRank) {
            sendAmount += toAdd;  // 只有expert属于dstRank才累加
        }
        
        dstAccumulated += toAdd;
        dstOffset += toAdd;
        if (dstOffset >= myRecvCntValue) {
            dstExpertIdx++;
            dstOffset = 0;
        }
    }
    
    recvProgressExpertIdx[dstRank] = dstExpertIdx;
    recvProgressExpertOffset[dstRank] = dstOffset;
    alltoAllvSendCnt[dstRank] = sendAmount * axis;
}
```

### 8.2 1卡详细轮次计算

**1卡已知信息**：
- 接收buffer: 所有卡的recvCount数组
- 0卡recvCount = [10, 20, 30, 40]（总量100）
- 1卡recvCount = [50, 60, 70, 80]（总量260）
- 最大卡是1卡，接收总量260
- 最大卡baseA = 40
- 总轮次 = ceil(260/40) = 7轮
- 0卡baseA = ceil(100/7) = 15
- 1卡baseA = ceil(260/7) = 37（向上取整确保7轮完成）

**1卡每轮计算**：

第1轮：
  0卡本轮接收15：
    接收量对应recvCount中的量：[10, 5, 0, 0]（从接收buffer0卡位置读取）
    recvCount剩余量：[0, 15, 30, 40]
    说明：expert0接收10（完成），expert1接收5（剩余15）
  1卡本轮接收40：
    接收量对应recvCount中的量：[40, 0, 0, 0]（从接收buffer1卡位置读取）
    recvCount剩余量：[10, 60, 70, 80]
    说明：expert0接收40（剩余10）
  发送统计：
    发送给0卡：本轮0卡从本卡接收的数据（1卡路由到expert0-1）
    发送给1卡：本轮1卡从本卡接收的数据（1卡路由到expert2-3）
  结果：发送0卡 X，发送1卡 40，接收0卡 X，接收1卡 40

### 8.3 发送端判断逻辑详解

**核心思想**：发送端模拟目标卡(dstRank)的接收过程，判断dstRank本轮接收的数据中是否有本卡的数据。

**判断步骤**：

```
发送给dstRank的本轮发送量计算：
1. 获取dstRank的进度：recvProgressExpertIdx[dstRank]、recvProgressExpertOffset[dstRank]
2. 模拟dstRank本轮接收过程：
   - dstAccumulated = 0（本轮累积接收量）
   - dstExpertIdx = recvProgressExpertIdx[dstRank]（当前expert索引）
   - dstOffset = recvProgressExpertOffset[dstRank]（当前expert偏移）
   
3. 外层循环：遍历dstRank的recvCount（卡号+专家顺序）
   for (累积接收量 < baseAPerRank[dstRank]) {
     currExpertIdx = dstExpertIdx
     
     // 从接收buffer获取dstRank路由到当前expert的数据量
     // 接收buffer布局：[dstRank][srcRank][expertIdx] 或扁平化索引
     // recvCount[srcRank][expertIdx] = dstRank路由到expert的数据量
     
     // 遍历所有srcRank，累积计算本轮接收量
     dstRecvTotal = 0
     for (srcRank = 0; srcRank < epWorldSize; srcRank++) {
       recvCount[srcRank][currExpertIdx] = 接收buffer.GetValue(dstRank, srcRank, currExpertIdx)
       dstRecvTotal += recvCount[srcRank][currExpertIdx]
     }
     
     // 本轮从当前expert接收的数量
     remaining = dstRecvTotal - dstOffset
     toAdd = Mc2Min(remaining, baseAPerRank[dstRank] - dstAccumulated)
     
     // 判断：当前expert本轮接收的数据中，是否有本卡的数据
     // 如果：srcRank == 本卡rankId
     // 则：本卡发送给dstRank toAdd量（按本卡路由比例）
     
     for (srcRank = 0; srcRank < epWorldSize; srcRank++) {
       recvCountSrcRank = recvCount[srcRank][currExpertIdx]
       srcRankToAdd = (recvCountSrcRank * toAdd) / dstRecvTotal  // 按路由比例分配
       
       // 关键判断：srcRank等于本卡时，累加发送量
       if (srcRank == rankId) {
         sendAmount += srcRankToAdd  // 本卡需要发送给dstRank的数据量
       }
       
       // 按srcRank累加recvCnt[srcRank]（接收端语义）
       alltoAllvRecvCnt[srcRank] += srcRankToAdd * axis
     }
     
     dstAccumulated += toAdd
     dstOffset += toAdd
     
     // 当前expert接收完，移动到下一个expert
     if (dstOffset >= dstRecvTotal) {
       dstExpertIdx++
       dstOffset = 0
     }
   }
   
4. 更新dstRank的进度：
   recvProgressExpertIdx[dstRank] = dstExpertIdx
   recvProgressExpertOffset[dstRank] = dstOffset
   
5. 计算发送量：
   alltoAllvSendCnt[dstRank] = sendAmount * axis
```

**关键理解**：
- recvCount虽然表面是1维数组，但实际逻辑是 `recvCount[srcRank][expertIdx]`
- 接收buffer存储：每张卡的路由数据，按卡号索引
- 外层循环卡号（模拟接收顺序），内层循环专家号（累积接收量）
- 判断 `srcRank == rankId` 时，本卡需要发送数据给dstRank
- recvCnt[srcRank]按srcRank路由比例分配（接收端语义）

### 8.3 关键理解总结
