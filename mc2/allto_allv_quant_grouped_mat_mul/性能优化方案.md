# AlltoAllvQuantGroupedMatMul 性能优化方案

## 一、核心思想

### 1.1 负载均衡原则

**总轮次**：基于最大接收量卡的接收总量。
```
totalRound = ceil(maxRecvSum / baseA)
```

**每轮发送量**：等于目标卡本轮接收需求。
```
本轮发送[src→dst] = min(baseA, dst从src总需求 - 已发送)
```

### 1.2 数据布局

**通信前（xGM）**：按专家排列
```
[专家0数据 | 专家1数据 | 专家2数据]
```

**通信后（recvBuffer）**：按发送卡排列
```
[卡0数据 | 卡1数据 | 卡2数据 | 卡3数据]
每卡数据内：[专家0片段 | 专家1片段 | 专家2片段]
```

## 二、地址偏移计算

### 2.1 A矩阵（xGM，通信输出）

**来源**：recvBuffer，从workspace起始位置

**偏移计算**：
```
xOffset[第N轮] = 前N轮接收总量 * CeilDiv(H1, PACK_FACTOR)

举例：
第0轮：xOffset = 0
第1轮：xOffset = 第0轮接收总量 * 4096
       （假设第0轮接收120 tokens，则 xOffset = 120 * 4096）
```

### 2.2 B矩阵（wGM，权重）

**来源**：权重地址，按专家索引偏移

**偏移计算**：
```
wOffset[专家M] = M * H1 * N1

举例（H1=4096, N1=4096）：
专家0：wOffset = 0
专家1：wOffset = 1 * 4096 * 4096 = 16MB
专家2：wOffset = 2 * 4096 * 4096 = 32MB
```

**注意**：权重地址固定，不随轮次变化。

### 2.3 C矩阵（yGM，输出）

**来源**：输出地址，按专家和轮次累积

**偏移计算**：
```
yOffset[专家M, 第N轮] = 前面专家总输出 + 当前专家前N轮输出

举例（专家0总60 tokens, 专家1总120 tokens, baseA=30）：
专家0第0轮：yOffset = 0
专家0第1轮：yOffset = 30 * N1 = 122880
专家1第0轮：yOffset = 60 * N1 = 245760
专家1第1轮：yOffset = 60 * N1 + 30 * N1 = 368640
```

### 2.4 Workspace布局

```
workspace基址
├── recvBuffer      (通信输出，A矩阵输入)
├── scaleCommOut    (MX场景Scale通信输出)
├── preCommBuffer   (预通信recvCount交换)
├── groupList       (GMM groupNum参数)
└── ptrTable        (GetTensorAddr指针表，4个slot)
```

## 三、通信量计算

### 3.1 发送量

**核心逻辑**：按目标卡的接收需求切分

```
对于每个目标卡 dstRank：
    发送量[dstRank] = Σ(每个专家本轮接收需求) * CeilDiv(H1, PACK_FACTOR)
    
    其中：本轮接收需求 = min(baseA, 总需求 - 已接收)
```

### 3.2 接收量

**核心逻辑**：与发送量语义相同

```
对于每个来源卡 srcRank：
    接收量[srcRank] = Σ(每个专家本轮接收需求) * CeilDiv(H1, PACK_FACTOR)
```

### 3.3 偏移量

```
发送偏移[第N轮] = 前N轮已发送总量
接收偏移[第N轮] = 前N轮已接收总量
```

## 四、计算层

### 4.1 groupList设置

**核心逻辑**：累积每个专家的M值

```
cumulativeM = 0
对于每个专家：
    curRoundTokens = min(baseA, 总tokens - 已处理)
    cumulativeM += curRoundTokens
    groupList[专家] = cumulativeM
```

**举例（baseA=30）**：
```
专家0：总60，本轮30，groupList[0]=30
专家1：总120，本轮30，groupList[1]=60
专家2：总180，本轮30，groupList[2]=90
```

### 4.2 cOffsetList设置

**核心逻辑**：每个专家的输出偏移

```
cOffset = 0
对于每个专家：
    cOffsetList[专家] = cOffset
    cOffset += curRoundTokens * N1
```

**举例（N1=4096）**：
```
专家0：cOffset[0] = 0
专家1：cOffset[1] = 30 * 4096 = 122880
专家2：cOffset[2] = 60 * 4096 = 245760
```

## 五、Scheduler双层循环

**handle限制**：最多64个并发handle

```
每批次最大轮次：
    MX场景：31轮（每轮2handle：数据+scale）
    TT场景：63轮（每轮1handle）

批次数量 = ceil(totalRound / 每批次最大轮次)

外层循环：批次
    内层循环：轮次
        MX场景：发起Scale通信
        发起数据通信
        MX场景：等待Scale
        等待数据
        同步
        执行ProcessAll
```

## 六、4卡3专家举例

### 6.1 数据设定

| 卡 | 总发送 | 总接收 |
|----|--------|--------|
| 0卡 | 240 | 180 |
| 1卡 | 300 | 240 |
| 2卡 | 180 | **360**（最大） |
| 3卡 | 300 | 180 |

**baseA** = 30，**totalRound** = 360/30 = 12轮

### 6.2 第0轮通信量

| 卡 | 发送 | 接收 |
|----|------|------|
| 0卡 | 发给1/2/3卡各30，共90 | 从1/2/3卡各30，共90 |
| 1卡 | 发给0/2/3卡各30，共90 | 从0/2/3卡各30，共90 |
| 2卡 | 发给0/1/3卡各30，共90 | 从0/1/3卡各30，共90 |
| 3卡 | 发给0/1/2卡各30，共90 | 从0/1/2卡各30，共90 |

### 6.3 地址偏移举例

**A矩阵（H1=4096）**：
```
第0轮：xGM = workspace + 0
第1轮：xGM = workspace + 360 * 4096（第0轮接收360 tokens）
```

**C矩阵（N1=4096）**：
```
专家0第0轮：yGM = output + 0
专家1第0轮：yGM = output + 30 * 4096 = 122880
专家0第1轮：yGM = output + 30 * 4096 = 122880
```
