# matmul_all_reduce 算子 A5 架构通信引擎默认值修改报告

## 1. 修改概述

本次修改将 matmul_all_reduce 算子在 A5 架构（DAV_3510）下的默认通信引擎从 CCU 改为 AICPU，涉及 aclnn 接口、动态图和静态图三条路径。

### 修改原因
- A5 架构需要默认使用 AICPU 作为通信引擎以获得更好的性能或兼容性

### 修改范围
- **aclnn 接口路径**: 修改所有 aclnn API 实现
- **动态图/静态图路径**: 修改 op_graph 相关代码

### 3.3 动态图/静态图路径修改

修改 `matmul_all_reduce_gen_task.cpp`，对于 A5 架构：
1. 当 commMode 为空字符串或 nullptr 时，使用 AICPU 路径
2. 仅当 commMode 显式指定为 "ccu" 时，才使用 CCU 路径

#### 3.3.1 MatmulAllReduceCalcParamFunc 函数

| 条件 | 原行为 | 新行为 |
|------|-------|-------|
| attrs == nullptr | 使用 CCU | 使用 AICPU |
| commModeStr == nullptr | 使用 CCU | 使用 AICPU |
| commModeStr == "" | 使用 CCU | 使用 AICPU |
| commModeStr == "ccu" | 使用 CCU | 使用 CCU |
| commModeStr == "ai_cpu" | 使用 AICPU | 使用 AICPU |

**修改后的代码逻辑**：
```cpp
if (IsTargetPlatformNpuArch(context->GetNodeName(), NPUARCH_A5)) {
    const char *commModeStr = attrs->GetAttrPointer<char>(...);
    if (commModeStr == nullptr) {
        return AICPU CalcParamFunc;  // 默认改为 AICPU
    } else if (std::strcmp(commModeStr, "ccu") == 0) {
        return CCU CalcParamFunc;     // 显式指定 ccu 才使用 CCU
    } else if (std::strcmp(commModeStr, "") == 0) {
        return AICPU CalcParamFunc;  // 空字符串默认改为 AICPU
    }
}
```

#### 3.3.2 MatmulAllReduceGenTaskFunc 函数

| 条件 | 原行为 | 新行为 |
|------|-------|-------|
| attrs == nullptr | 使用 CCU (Mc2Arch35) | 使用 AICPU (MatmulAllReduceGenTaskOpsUtils) |
| commModeStr == nullptr | 使用 CCU (Mc2Arch35) | 使用 AICPU (MatmulAllReduceGenTaskOpsUtils) |
| commModeStr == "" | 使用 CCU (Mc2Arch35) | 使用 AICPU (MatmulAllReduceGenTaskOpsUtils) |
| commModeStr == "ccu" | 使用 CCU (Mc2Arch35) | 使用 CCU (Mc2Arch35) |
| commModeStr == "ai_cpu" | 使用 AICPU (MatmulAllReduceGenTaskOpsUtils) | 使用 AICPU (MatmulAllReduceGenTaskOpsUtils) |

**修改后的代码逻辑**：
```cpp
if (IsTargetPlatformNpuArch(context->GetNodeName(), NPUARCH_A5)) {
    const char *commModeStr = attrs->GetAttrPointer<char>(...);
    if (commModeStr == nullptr) {
        return MatmulAllReduceGenTaskOpsUtils::MatmulAllReduceGenTaskCallback;  // AICPU
    } else if (std::strcmp(commModeStr, "ccu") == 0) {
        return Mc2Arch35GenTaskOpsUtils::Mc2Arch35GenTaskCallBack;  // CCU
    } else if (std::strcmp(commModeStr, "") == 0) {
        return MatmulAllReduceGenTaskOpsUtils::MatmulAllReduceGenTaskCallback;  // AICPU
    }
}
```

## 4. 影响分析

### 4.1 A5 架构影响

| 场景 | 修改前行为 | 修改后行为 |
|------|----------|----------|
| 调用无 commmode 参数的接口 | 使用 CCU | 使用 AICPU |
| 调用有 commmode 参数的接口，传入空字符串 | 使用 CCU | 使用 AICPU |
| 调用有 commmode 参数的接口，传入 "ccu" | 使用 CCU | 使用 CCU（保持不变） |
| 调用有 commmode 参数的接口，传入 "ai_cpu" | 使用 AICPU | 使用 AICPU（保持不变） |
| 动态图/静态图，commMode 属性为空或未设置 | 使用 CCU | 使用 AICPU |
| 动态图/静态图，commMode 属性显式为 "ccu" | 使用 CCU | 使用 CCU（保持不变） |

### 4.2 其他架构影响

- **A2 架构**: 无影响，保持原有 AICPU 默认行为
- **其他架构**: 无影响，保持原有行为

### 4.3 兼容性说明

1. **向后兼容性**: 对于显式指定 "ccu" 的调用，行为不变
2. **默认行为变更**: 对于不指定或指定空字符串的调用，A5 架构将使用 AICPU 而非 CCU
3. **影响范围**: 仅影响 A5 架构，其他架构完全不受影响

| 类型 | 常量 | 说明 |

| 参数值 | 原映射（A5） | 新映射（A5） |
|-------|------------|------------|
| `"ai_cpu"` | COMM_MODE_AICPU | COMM_MODE_AICPU |
| `"ccu"` | COMM_MODE_CCU | COMM_MODE_CCU |
| `""` (空字符串) | COMM_MODE_CCU | COMM_MODE_AICPU |
| `nullptr` | 使用默认值 "ccu" | 使用默认值 "" |
