## 4. 时延测试结果

| 数据包大小 | 平均时延 (us) | 最小时延 (us) | 最大时延 (us) | 标准差 (us) | P50 (us) | P90 (us) | P99 (us) |
|-----------|--------------|--------------|--------------|-------------|----------|----------|----------|
|  |  |  |  |  |  |  |  |

**抖动分析说明：**

- 时延抖动 = 标准差 / 平均时延，用于衡量通信稳定性
- P50/P90/P99 分别表示 50%/90%/99% 的通信请求在此时间内完成
- 正常情况下 P90 与 P50 差值应较小，若 P99 远大于 P90 说明存在偶发高时延

## 6. 与现有带宽测试工具对比

| 对比项 | bandwidth_test (AlltoAll) | urma_p2p_benchmark (P2P) |
|--------|--------------------------|--------------------------|
| 通信模式 | AlltoAll Dispatch（多rank同时收发） | Point-to-Point（指定rank间单向通信） |
| 测试维度 | 全局聚合带宽 | 单链路带宽/时延/头开销 |
| 通信协议 | MTE / URMA | URMA |
| 适用场景 | MOE 场景 AlltoAll 带宽验证 | URMA P2P 链路性能基线测量 |
| 数据流模型 | 多对多（N×N） | 一对一（1×1） |
| 输出指标 | 聚合带宽 | 单链路时延、带宽、头开销 |
