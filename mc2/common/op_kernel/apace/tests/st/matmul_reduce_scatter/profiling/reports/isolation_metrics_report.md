## 指标定义

```
四分量隔离: T_mm(compute_only) | T_a2a(comm_only 纯AllToAll+fence) | T_rs(reduce_only)
T_before = serial 模式实测（三方逐 tile 串行: Wait→PUT→fence→RS, 无跨 tile 重叠）
T_after  = perf 模式实测（正式流水: matmul ∥ AllToAll(t) ∥ reduceSum(t-1)）

加速比 = T_before / T_after

T_floor = max(T_mm, T_a2a, T_rs)                # 三方完美流水理论下界
掩盖率(修正) = (T_before - T_after) / (T_before - T_floor)   # 恒 ≤ 1
```

> **口径说明**: 两阶段公式以 min(T_mm, T_comm) 为分母且 T_comm 混入 reduceSum 时会出现掩盖率 >1;
> 修正口径分母为三方完美流水理论最大可节省量，物理含义 = 「实际流水达到理论流水收益的程度」，恒 ≤ 1。
> serial 为逐 tile 串行 — AIC 下一 tile 的 matmul 仍可与 AIV 当前 tile 的 PUT/RS 并行
> (AIC 不受 AIV 节奏反压)，故 T_before 略低于三分量简单加和，分解方向自洽。

## 关键发现（当前代码）

1. **通信 Bound 族（6 case）流水掩盖最深**: 掩盖率中位 **0.83**，row87 (16384,512,4096,r4)
   达 **0.89**（R=0.13）— 通信深度主导场景下，PUT 传输与 AIC matmul / AIV reduceSum 的三方
   重叠已接近完美流水
2. **均衡族（5 case）掩盖率中位 0.57**: 掩盖空间受三方分量比例约束；fence 重叠化 + 尾声批量
   RS 已消化大部分可重叠窗口
3. **row67 (6144,5472,16384,r4) 为唯一计算 Bound（R=1.60）**: T_floor = T_mm，融合上限即
   matmul 本身（T_after 仅高出 T_mm 14.5%）— 大 K tiling 调优（P2-AIC，递延方向）是该族
   唯一剩余优化空间
4. **全部 12 case 融合加速比 ≥ 1.02x**: 融合正收益性确立；最大 **1.48x**（row16，小 N T=1
   单 tile — P1-b tiling 下逐轮固定开销已消除）
5. **口径自洽**: 全部掩盖率 ≤ 1.0；serial 逐 tile 串行下 AIC 前行 matmul 与 AIV 当前 tile 的
   PUT/RS 天然并行，T_before 略低于三分量加和（残差 avg −481.8us），分解方向自洽
