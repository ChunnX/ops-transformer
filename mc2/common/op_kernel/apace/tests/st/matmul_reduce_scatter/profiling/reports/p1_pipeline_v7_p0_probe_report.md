## 一、P1-a: v7 fence 重叠化（已落地 @ 865dc1ee4）

### 设计

```
v6: #1(t) → Commit(t) → Drain(t) → fence(t)          → [next] WaitFlag(t+1) → #1(t+1)
                                      ↑ fence 串行占用通道空闲窗口
v7: #1(t) → Commit(t) → fence(t-1) → Drain(t)         → [next] WaitFlag(t+1) → #1(t+1)
                        ↑ 与 PUT(t) 传输重叠 (对端 Drain(t-1) 上轮已完成, 握手快速通过)
计算核: #1(t) → [本地轮询 R 个 fence 计数槽 >= t] → RS(t-1)   ← 替代经 #1(t+1) 全核传播
尾声: 通信核 fence(T-1) ‖ 计算核轮询 + RS(T-1)（无终局 SyncAll, 每核 T 次 barrier）
```

- fence 计数槽 = teamSyncCounter（本 rank win barrier 区），纯本地 GM 读，R 槽一次扫描 ~2-4us
- fence(t-1) 结论不再占用全核 barrier 轮次传播，RS(t-1) lag 保持 1 turn，尾声零额外 barrier

## 二、P1-b: 小 N tile 尺寸策略（已落地 cases.csv）

### headM 扫描（v7 二进制，perf 模式内联精度全 PASS）

| case 族 | headM (T) → latency(us) | 结论 |
|---|---|---|
| row17 (4096,5120,640,4) | 128(8)→162.9 / 256(4)→140.4 / 512(2)→139.3 / **1024(1)→136.2** | 单 tile 最优, **-16.4%** |
| row16 (4096,5120,640,2) | 512(4)→129.1 / 1024(2)→152.8 / **2048(1)→119.9** | 单 tile 最优, **-7.1%** (非单调) |
| row10 (2048,3584,4096,4) | **128(4)→154.5** / 256(2)→168.7 / 512(1)→203.7 | 默认已最优, T=1 恶化 +32% |
| row47 (4096,4096,12288,4) | 128(8)→908.7 / **256(4)→823.2** / 512(2)→915.4 | T=4 甜点, **-9.4%** |

优胜配置复测确认（偏差 <0.2%）：row16@2048=119.7 / row17@1024=136.4 / row47@256=822.0。

**规律**: tile 字节数决定最优 T — 小 N (640) 时每 tile 仅 160KB~2.5MB，逐轮固定开销
(WQE+drain+fence+barrier) 占比过高，减轮次（甚至 T=1 牺牲重叠）净收益为正；
大 N (12288) 时 tile 传输时间长，T=4 重叠粒度与轮次开销平衡最佳；均衡 case 默认 T=4 已最优。

**落地**: cases.csv rows 16/17/47 headM 更新为 2048/1024/256（tiling 策略参数，非基准常量）。

## 三、P0: 多通道 PUT 带宽扩展探针（确定性否定结论，代码已回退）

### 探针方法

1. `HcclChannelAcquire` 重复调用（相同 endpoint pair）→ **幂等，返回同一 channel**（日志实测 ch1==ch2）
2. linkIdx=1（第二条物理 link）→ **本机拓扑每 rank pair 仅 1 条 UBC_CTP link**
3. `HcclChannelAcquireWithConfig` + `IS_SHARED_QUEUE=true` + tag → **成功创建独立第二 channel**（ch1=0x...3e000,
   ch2=0x...43000），kernel 侧 tile 对半拆分双通道 PUT + 双 drain（fence 证明链不变）

### 结果：无带宽增益

| row | v7 单通道 (us) | v7 双通道 (us) | Δ |
|----|---------|---------|------|
| 1 (r2) | 2362.1 | 2357.4 | -0.20% |
| 27 | 485.0 | 483.6 | -0.29% |
| 47 | 909.8 | 909.8 | +0.13% |
| 86 (r2) | 1538.0 | 1547.3 | +0.61% |
| 87 | 847.5 | 848.9 | +0.16% |
| 89 | 1050.1 | 1051.2 | +0.11% |

**结论**: 全部 ±0.6% 噪声级。shared-queue 多 channel 共享同一 jetty（传输队列对），
**单 rank pair ~40GB/s 是链路/jetty 物理上限，非通道队列限制** — 在本机拓扑（单机 4 卡、
每对 rank 单 link）下多通道 PUT 无法扩展带宽。P0 在本机**不可行**，代码已回退，
探针补丁已随代码回退（多 link 跨机拓扑如需复验, 可按第三节方法重建）。
