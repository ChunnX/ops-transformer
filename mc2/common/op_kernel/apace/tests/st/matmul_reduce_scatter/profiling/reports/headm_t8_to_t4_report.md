## 五、方法论沉淀

1. **T=2（首尾两块）是结构性劣点**: 首轮 PUT 暴露 ~50% 通信量 + 仅 1 个重叠周期, 任何 case 不建议
2. **headM < Blaze baseM(256) 是隐形 matmul 税**: localHead problem m=headM 直接压低 baseM, 大 K 时 B 重复装载翻倍——headM ≥ 256 应作为 tiling 下界约束
3. **同步税已非轮次主导**: v6/v7 之后 baseM 相同前提下 T=8 vs T=4 差异 ±3% 内, 减轮收益主要来自 baseM 效应而非同步开销
4. **非单调性**: K=5120 与 K=2304×大N 反例存在 → 逐 case 扫描落地, 不做族级一刀切
