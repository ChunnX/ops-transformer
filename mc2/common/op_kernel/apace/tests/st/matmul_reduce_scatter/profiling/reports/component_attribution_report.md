# 大额收益组件归因分析报告

- **日期**: 2026-09-29
- **定位**: 组合 tiling 表 6 个大额收益 case 的收益来源定位与机制分析（row27 顺序机制闭合）
- **数据**: 5 case × 双配置四分量隔离（probe v2）+ 顺序 A/B 补齐，56 runs 同日单场次；
  row67 沿用统一复测数据
- **环境**: Ascend950PR ×4, CANN 9.2.0, msprof task-based（后 5 次均值 / 跨 rank 取 max）
- **上游文档**: [tiling_strategy_experiment_report.md](tiling_strategy_experiment_report.md)（实验全记录）、
  [isolation_metrics_report.md](isolation_metrics_report.md)（隔离指标）

## 1. 背景与目的

组合 tiling 表落地（21 case geomean −9.65%）后存在两个待解问题：

1. **公式接管 case（−15% ~ −28%）的收益来源分量是什么**——仅有 row67 的 T_mm −20% 单点证据
2. **row27 顺序开关收益（−8.2%）的机制**——悬而未决（第 9 节遗留问题）

本报告用双配置四分量隔离逐一回答。

交叉验证：新配置 T_after 与 Phase 3 全新 A/B 一致（row69 2591 vs 2589 / row57 1782 vs 1791 /
row33 996 vs 987 / row51 1745 vs 1737，偏差 <1%）。

### 3.2 贡献占比：T_mm 单一来源确凿

| row | ΔT_after | ΔT_mm | **mm 贡献占比** | 解读 |
|---|---|---|---|---|
| 69 | −1017 | −1051 | **103%** | T_mm 降幅完全覆盖并略超 T_after 降幅 |
| 57 | −635 | −689 | **109%** | 同上（T_a2a −3% 小幅对冲） |
| 33 | −264 | −352 | **133%** | T_mm 超出部分被 serial 侧吸收 |
| 51 | −317 | −375 | **118%** | 同上 |

**结论**：公式收益为**单一来源**——纯 matmul 分量的 scope 效率提升；通信分量不变（通信量与
tiling 无关），RS 分量 −8%~−13% 次要（tile 变大轮次减少）。

### 3.3 Bound 迁移：计算 Bound → 均衡

| row | R 值（旧→新） | Bound 迁移 | 掩盖率 |
|---|---|---|---|
| 69 | 1.67 → 1.18 | **计算 Bound → 均衡** | 0.15 → 0.11 |
| 57 | 1.68 → 1.19 | **计算 Bound → 均衡** | 0.23 → **0.46（翻倍）** |
| 33 | 1.73 → 1.21 | **计算 Bound → 均衡** | 0.29 → 0.26 |
| 51 | 1.62 → 1.35 | **计算 Bound → 均衡** | 0.16 → 0.20 |

**解读**：tileM 128→256 不只是加速 matmul，而是**重构了算子的 Bound 画像**——4 case 全部从
计算 Bound（R≈1.7）迁移到均衡区（R≈1.2-1.4），matmul 与通信重新配平。掩盖率随迁移方向分化：
row57（旧掩盖率最低的计算 Bound case）翻倍至 0.46；row69 因 T_before 同步大幅下降（serial
含同一 matmul）掩盖率反降。**本质：128 tiling 对大 K 大 N r4 case 的 matmul 过度切分，
公式 tileM 恰在此场景恢复配平**——这是占用率准则在该族正确的机理根源。

### 3.4 T_mm 降幅的 shape 分簇

| (K, N) 族 | case | T_mm 降幅 |
|---|---|---|
| K=6144, N=18432 | row69 / row57 / row33 | **−33% ~ −34%** |
| K=5472, N=16384 | row51 / row67 | −20% ~ −21% |

matmul scope 效率收益与问题规模强相关（大 K 大 N 族收益更大），可为后续 tiling 调优提供
收益预期标尺。

## 4. row27 顺序机制：(128,L0) vs (128,L1)

### 4.1 双配置分量对比

| 分量 | L0 | L1 | Δ | 判读 |
|---|---|---|---|---|
| **T_mm（纯 matmul）** | 384.1 | 354.9 | **−7.59%** | **收益来源：AIC 侧执行效率变化** |
| T_a2a（纯 AllToAll） | 306.4 | 310.7 | +1.38% | 不变（顺序不影响通信）✓ |
| T_rs（纯 reduceSum） | 100.4 | 99.9 | −0.57% | 不变 ✓ |
| T_before（serial） | 556.8 | 531.1 | −4.63% | 降幅小于 T_mm（serial 被 AIV 节奏拉平） |
| **T_after（融合）** | 481.7 | 439.4 | **−8.78%** | 与历史 A/B 一致（L0 479~483 / L1 437~440） |
| 掩盖率 / 加速比 | 0.43 / 1.16x | **0.52 / 1.21x** | — | R 值 0.94→0.86，均衡区不变 |

ΔT_mm=−29.2us 占 ΔT_after=−42.3us 的 **69%**，其余为融合流水交互项。

### 4.2 机制推理：fixpipe 尾部暴露

- **假说**：scope 的 fixpipe（L0C→GM）写与后续 scope 的 M/MTE 计算在不同 pipe 上并行。
  REMOTE 先行（L1）时，其**大 fixpipe 尾部（3×tileM 行）隐藏于 LOCAL 后续计算之下**，
  tile 以 LOCAL 的小 fixpipe 尾结束 → flag 提前；LOCAL 先行（L0）时，REMOTE 的大 fixpipe
  尾部裸露在 tile 末尾 → flag 延迟。
- **证据链**：① T_mm（纯计算路径，含 fixpipe）随顺序变化 −7.6%；② T_a2a/T_rs 完全不变
  （排除 AIV 重叠侧解释）；③ rank2（LOCAL/REMOTE 同构，fixpipe 尾等长）完全中性 ✓；
  ④ 收益随 tile 粒度变化（row27@128 −8%，@256 中性——Phase 1）。
- **与既有假说体系的闭合**：本证据将顺序收益定位于 **AIC 侧 matmul 执行效率**（组件级可测），
  与公式收益（matmul scope 效率）**同在 matmul 维度但机制不同**——一个改 scope 大小（tiling），
  一个改 scope 排序（fixpipe 尾隐藏），二者正交但在同一 case 上不可叠加
  （公式接管后顺序收益消失，实验三）。

### 4.3 遗留问题

- 顺序收益的 tile 粒度依赖定量模型（为何 @256 消失、row47 同构中性）——建议后续用
  op_summary pipe 利用率（MTE3/FIX 占比 L0 vs L1）做逐指令级确认
- mm 占比 69% 中剩余 31% 的流水交互项拆解

## 6. 结论

1. **公式收益 = 组件级**：T_mm 贡献占比 103%~133%（单一来源），Bound 从计算 Bound 迁移至均衡
   （R 1.7→1.2），降幅按 (K,N) 分簇（−33% / −21%）
2. **顺序收益 = 执行级**：T_mm −7.6%（fixpipe 尾部暴露），T_a2a/T_rs 不变，掩盖率 0.43→0.52
3. **两种收益机制正交**——组件级（scope 大小）vs 执行级（scope 排序），构成"替代互补"的
   机制基础：同一 case 上公式接管后顺序收益消失，但两者可分 case 组合
4. 实操含义：**tileM=128 对大 K 大 N r4 case 是 matmul 过度切分**，组合表按 case 恢复配平
   是大额收益的根源；顺序开关是独立的执行级优化，仅对特定粒度 case 有效
