## 达标判定：✅ 达标

- v2 3 级流水（mm→comm→reduceSum，PIPELINE_NUM=4 workspace 轮转）相比 v1 串行模式
  取得 ~2.48× 加速（143us → 57.6us），达到设计目标（DESIGN.md §1.3/§2.11：通过
  workspace 多 buffer 轮转提升通算并行度）。
- AIC cube 利用率 ~91%，mm 主导，通信与 reduceSum 基本被流水掩盖。
