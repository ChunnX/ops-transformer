# QkvRmsNormRopeCacheWithKScale 脑图节点

- QkvRmsNormRopeCacheWithKScale
  - 节点一：所有输入的类型
    - 基础约束
      - `D=128`
      - `0<Nq<=64`
      - `Nq=8*Nk`
      - `Nk=Nv`
      - `0<T<262144`
      - `headNums=[Nq,Nk,Nv]`
    - 必选普通输入 Tensor
      - `qkv`
        - 类型：BF16
        - 格式：ND
        - TND shape：`[T,Nq+Nk+Nv,128]`
        - NTD shape：`[Nq+Nk+Nv,T,128]`
        - 不支持非连续 Tensor
      - `qGamma`
        - 类型：FP32
        - shape：`[128]`
        - 作用：Q 分支 RMSNorm 权重
      - `kGamma`
        - 类型：FP32
        - shape：`[128]`
        - 作用：K 分支 RMSNorm 权重
      - `cosSin`
        - 类型：FP32
        - shape：`[MaxSeqLen,128]`
        - 前 64 列：cos
        - 后 64 列：sin
        - 第一维必须覆盖本次访问的全部位置
      - `slotMapping`
        - 类型：INT32
        - shape：`[T]`
        - 值域：`[0,BlockNum*BlockSize-1]`
        - 当前 800 例保证单次调用内 slot 唯一
    - 输入输出别名 Cache Tensor
      - 公共属性
        - `BlockSize=16`
        - 支持连续 Tensor
        - 支持满足正 stride 约束的非连续 Tensor
        - 只更新 `slotMapping` 指定的位置
      - `kCacheRef`
        - shape：`[BlockNum,Nk,BlockSize,128]`
        - RoPE 类型：FP8 E4M3FN
        - M-RoPE 类型：INT8
      - `vCacheRef`
        - shape：`[BlockNum,Nv,BlockSize,128]`
        - 类型：FP8 E4M3FN
      - `kScaleCacheRef`
        - shape：`[BlockNum,Nk,BlockSize,1]`
        - 类型：FP32
    - RoPE 专属位置输入
      - `queryStartLocOptional`
        - 类型：INT32
        - shape：`[Batch+1]`
        - 语义：本次调用各 batch token 数的前缀和
        - 约束：首元素为 0，末元素为 T
      - `seqLensOptional`
        - 类型：INT32
        - shape：`[Batch]`
        - 语义：追加本次 token 后的实际序列长度
      - presence 规则
        - `queryStartLocOptional` 与 `seqLensOptional` 必须同时存在
        - `mropePositionOptional` 不传
        - `mropeSectionOptional` 不传或为空
    - M-RoPE 专属位置输入
      - `mropePositionOptional`
        - 类型：INT32
        - shape：`[T,3]`
        - 第 0 列：T 坐标
        - 第 1 列：H 坐标
        - 第 2 列：W 坐标
      - `mropeSectionOptional`
        - 类型：INT64 数组
        - 内容：`[t,h,w]`
        - 长度：3
        - `t>=0`
        - `0<=h<=21`
        - `0<=w<=21`
        - `t+h+w<=64`
      - presence 规则
        - `mropePositionOptional` 与非空 `mropeSectionOptional` 必须同时存在
        - `queryStartLocOptional` 不传
        - `seqLensOptional` 不传
    - Q/K 公共计算输入
      - `rotationOptional`
        - 接口语义：必传
        - 类型：BF16
        - shape：`[128,128]`
        - 作用：Q/K 完成位置编码后共享右乘该矩阵
    - V 分支输入
      - `vScaleOptional`
        - 接口语义：必传
        - 类型：FP32
        - RoPE shape：`[Nv]`
        - RoPE 语义：按 V head 广播
        - M-RoPE shape：`[Nv,128]`
        - M-RoPE 语义：按 V head 和通道逐元素缩放
    - 属性类输入
      - `headNums`
        - 类型：INT64 数组
        - 长度：3
        - 内容：`[Nq,Nk,Nv]`
      - `layoutQkv`
        - 类型：字符串
        - 可选值：`TND`、`NTD`
        - 默认值：`TND`
        - 大小写敏感
      - `layoutQOut`
        - 类型：字符串
        - 可选值：`TND`、`NTD`
        - 默认值：`NTD`
        - 大小写敏感
      - `epsilon`
        - 类型：float
        - 作用：RMSNorm 防除零参数
      - `qQuantMode`
        - 类型：字符串
        - RoPE：`PerTokenPerHead`
        - M-RoPE：`NoQuant`
        - 默认值：`PerTokenPerHead`
  - 节点二：当前支持的模式组合
    - 场景判定
      - RoPE
        - 存在 `queryStartLocOptional + seqLensOptional`
        - 不存在 M-RoPE 位置输入
        - Q 使用 PerTokenPerHead 动态量化
        - Q 输出 FP8 E4M3FN
        - Q Scale 输出 FP32
        - K Cache 为 FP8 E4M3FN
      - M-RoPE
        - 存在 `mropePositionOptional + 非空mropeSectionOptional`
        - 不存在 RoPE batch 位置输入
        - Q 使用 NoQuant
        - Q 输出 BF16
        - Q Scale 为 None
        - K Cache 为 INT8
    - 4 种实际支持的场景与布局组合
      - M01：RoPE NTD→NTD
        - `qkv=[Nq+Nk+Nv,T,128]`
        - `qOut=[Nq,T,128]`
        - `qScale=[Nq,T]`
      - M02：RoPE TND→TND
        - `qkv=[T,Nq+Nk+Nv,128]`
        - `qOut=[T,Nq,128]`
        - `qScale=[T,Nq]`
      - M03：RoPE TND→NTD
        - 默认布局组合
        - `qkv=[T,Nq+Nk+Nv,128]`
        - `qOut=[Nq,T,128]`
        - `qScale=[Nq,T]`
      - M04：M-RoPE TND→TND
        - `qkv=[T,Nq+Nk+Nv,128]`
        - `qOut=[T,Nq,128]`
        - `qScale=None`
    - 支持模式数量
      - RoPE：3 种
      - M-RoPE：1 种
      - 合计：4 种

      - 目的
