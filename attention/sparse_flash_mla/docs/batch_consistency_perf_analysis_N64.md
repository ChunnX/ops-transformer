# SMLA `IS_BATCH_CONSISTENCY` 性能劣化分析（N1=64）

分析对象：`attention/sparse_flash_mla/op_kernel/arch35`
规格：`b = 核数`、`s1 = 1`、`s2 = 4096`、`d = 512`，每核处理一个 batch 的整段 S2。
N1=64 → 每核 M=64（`s1BaseSize=64`），每 AIV 子核 `halfMRealSize=32`。
`reductionBlockSize = 128` → 32 个规约块、每块 1 个基本块、核内两两规约 31 次。

## 1. SMLA 的 V0 dtype

SMLA 的 KV 输入就是 **bf16**（不是 fp8），V0 阶段是**直接 gather 拷贝，没有 dequant / 无 Vector 计算**：
`CopyIn8Block`（MTE2，GM→UB）→ `CopyOutKvUb2Gm`（MTE3，UB→GM）
（`sparse_flash_mla_csa_block_vector_arch35.h:693-705`，`CopyOutKvUb2Gm` 用 `Q_T`=bf16）。C1 也搬 **bf16**。

## 2. 各阶段 cycle（N64，题给）

| 阶段 | 队列 | cycles |
|---|---|---|
| Q MTE2 | AIC-MTE2 | 1201 |
| KV MTE2（C1） | AIC-MTE2 | 1852 |
| Matmul1 (QK) | AIC-Cube | 1024 |
| Matmul2 (PV) | AIC-Cube | 1024 |

| V0 Vector | AIV-V | 0 |

## 3. Pipeline 建模

| 队列 | 每 loop 发射顺序 | N64 单拍 |
|---|---|---|
| AIV-MTE2 | `a_t`(V0 load) → `m_{t-3}`(BC merge read) | 3556 / 2402 |
| AIV-MTE3 | `c_t`(V0 write) → `n_{t-3}`(BC merge write) | 3556 / 2402 |
| AIV-V | `b_t`(V0 vec) → `f_{t-2}`(V1) → `h_{t-3}`(V2) | 0 / 600 / 50 |
| AIC-MTE2 | `Q`（一次） → `d_{t-1}`(KV GM→L1) | 1201 / 1852 |
| AIC-Cube | `e_{t-2}`(Matmul1) → `g_{t-3}`(Matmul2) | 1024 / 1024 |

CV 依赖：`c_i→d_i`、`e_i→f_i`、`f_i→g_i`、`g_i→h_i`；BC：`h_i→m_i`、`m_i→n_i`、`n_i→m_{i+1}`。
Buffer 深度：stage0In=2, stage0Out=2, v0ResGm=3, **L1K=3**, bmm1=2, l1P=2, bmm2=1。同队列 FIFO。

## 4. 不开启

| 队列 | busy |
|---|---|
| AIV-MTE2 | **113,792** |
| AIV-MTE3 | **113,792** |
| AIV-V | 19,200 |
| AIC-MTE2 | 60,465 |
| AIC-Cube | 65,536 |

- 瓶颈：**AIV-MTE2 / AIV-MTE3 各 32×3556 = 113,792**（V0 bf16 gather 与写回）。
- **makespan = 122,272 cyc**。

## 5. 开启

| 队列 | busy |
|---|---|
| AIV-MTE2 | 188,254 |
| AIV-MTE3 | 190,656 |
| AIV-V | 20,800 |
| AIC-MTE2 | 60,465 |
| AIC-Cube | 65,536 |

- 临界环：
  ```
  m_i (2402) → a_{i+4} (3556) → b_{i+4} (0) → f_{i+2} (600) → h_{i+1} (50) → m_{i+1} (2402)
  周期 = 2402 + 3556 + 0 + 600 + 50 = 6608 cyc / 块
  ```
- **makespan = 218,318 cyc**。

### 阻塞点
1. **AIV-MTE2 被 merge 读回（2402）与 V0 gather（3556）叠加**：`m_i` 与 `a_{i+4}` 同队列 FIFO。
2. **merge 链串行**：`m_i→n_i→m_{i+1}` = 4804/块。
3. **CV 同步传导**：`c_i→d_i→…→h_i→m_i` 闭环，AIC（65,536）无法掩盖。
4. SMLA 的 V0 负载（113,792）较大，BC 额外开销（74,462）占比小，劣化比 QSMLA 低。

## 6. 结论

**三档 HBM 带宽下的结果（详见第 8~9 节）**：

| 场景 | 不开启 | 开启 | 耗时比 | 性能比 |
|---|---|---|---|---|
| HBM 4T（题给） | 122,272 cyc | 218,318 cyc | **1.79×** | 0.56× |
| HBM 1.6T（V100） | 301,072 cyc | 520,445 cyc | **1.73×** | 0.58× |
| HBM 1.4T（V100） | 343,643 cyc | 592,385 cyc | **1.72×** | 0.58× |

**SMLA N1=64：开启后耗时约为不开启的 1.72~1.79 倍，性能约为不开启的 0.56~0.58 倍。**
- 4T：不开启瓶颈 AIV-MTE2/MTE3（各 3556 cyc/块）；开启临界环 `m→a→b→f→h→m = 6608 cyc/块`。
- 1.6T / 1.4T：V0 MTE3 绝对值增大后 BC 额外开销被摊薄，瓶颈为 AIV-MTE3，劣化略降。
- 1.6T ↔ 1.4T 比值几乎不变，仅绝对耗时 ×1.14。

## 8. V100（HBM 1.6T）带宽折算

题给数据在 HBM **4T** 环境测得；V100 环境 HBM **1.6T**，比值 **4/1.6 = 2.5×**。
HBM 读写阶段（`Q MTE2`、`KV MTE2`、`V0 MTE2`、`V0 MTE3`、`BC merge MTE2/MTE3`）×2.5；片上阶段（`Matmul`、`V1`、`V2`；SMLA 无 V0 Vector）不变。

折算后各阶段 cycle：

| 阶段 | 4T | 1.6T |
|---|---|---|
| Q MTE2 | 1201 | 3002 |
| KV MTE2 | 1852 | 4630 |
| V0 MTE2 | 3556 | 8890 |
| V0 Vector | 0 | 0 |
| V0 MTE3 | 3556 | 8890 |
| Matmul1 / Matmul2 | 1024 / 1024 | 1024 / 1024 |
| V1 / V2 | 600 / 50 | 600 / 50 |
| merge MTE2 / MTE3 | 2402 | 6005 |

结果：

| 队列 | 不开启 busy | 开启 busy |
|---|---|---|
| AIV-MTE2 | 284,480 | 470,635 |
| AIV-MTE3 | 284,480 | 476,640 |
| AIV-V | 19,200 | 20,800 |
| AIC-MTE2 | 151,162 | 151,162 |
| AIC-Cube | 65,536 | 65,536 |
| **makespan** | **301,072** | **520,445** |

- 不开启瓶颈：**AIV-MTE2 / AIV-MTE3 各 32×8890 = 284,480**。
- 开启瓶颈：**AIV-MTE3 = 32×8890 + 32×6005 = 476,640**（资源环 `c+n = 14,895/块`）。
- **开启后耗时约为不开启的 1.73 倍，性能约为不开启的 0.58 倍。**

| 指标 | 4T（原） | 1.6T（折算） |
|---|---|---|
| 不开启 | 122,272 | 301,072 |
| 开启 | 218,318 | 520,445 |
| 耗时比 | 1.79× | **1.73×** |
| 性能比 | 0.56× | **0.58×** |
