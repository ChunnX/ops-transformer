# SMLA `IS_BATCH_CONSISTENCY` 性能劣化分析（N1=128）

分析对象：`attention/sparse_flash_mla/op_kernel/arch35`
规格：`b = 核数`、`s1 = 1`、`s2 = 4096`、`d = 512`。32 个规约块、每块 1 个基本块、核内两两规约 31 次。

> 本文按 **N1=128（单核 M=128）** 推导：以 N64 为基准，把与 M 相关的阶段 ×2。
> 注意：按当前代码，`gSize>64` 走 **Split-G**，每核仍是 M=64；第 6 节说明。
> N1=64 版本见同目录 `batch_consistency_perf_analysis_N64.md`。

## 1. SMLA 的 V0 dtype

SMLA 的 KV 输入就是 **bf16**，V0 是直接 gather 拷贝（无 dequant、无 Vector），C1 也搬 **bf16**。

## 2. 各阶段 cycle（N128）

| 阶段 | 队列 | N64 | N128 |
|---|---|---|---|
| Q MTE2 | AIC-MTE2 | 1201 | 2402 |
| KV MTE2（C1） | AIC-MTE2 | 1852 | 1852 |
| Matmul1 (QK) | AIC-Cube | 1024 | 2048 |
| Matmul2 (PV) | AIC-Cube | 1024 | 2048 |
| V0 MTE2 | AIV-MTE2 | 3556 | 3556 |
| V0 Vector | AIV-V | 0 | 0 |
| V0 MTE3 | AIV-MTE3 | 3556 | 3556 |
| V1 Vector | AIV-V | 600 | 1200 |
| V2 Vector | AIV-V | 50 | 100 |
| BC merge 读回 | AIV-MTE2 | 2402 | 4804 |
| BC merge 写回 | AIV-MTE3 | 2402 | 4804 |

## 3. 不开启

| 队列 | busy |
|---|---|
| AIV-MTE2 | 113,792 |
| AIV-MTE3 | 113,792 |
| AIV-V | 38,400 |
| AIC-MTE2 | 61,666 |
| AIC-Cube | **131,072** |

- 瓶颈：**AIC-Cube = 32×(2048+2048) = 131,072**（V0 3556 被掩盖）。
- **makespan = 141,544 cyc**。

## 4. 开启

| 队列 | busy |
|---|---|
| AIV-MTE2 | 262,716 |
| AIV-MTE3 | 267,520 |
| AIV-V | 41,600 |
| AIC-MTE2 | 61,666 |
| AIC-Cube | 131,072 |

- 临界环（取最大）：
  - `m→a→b→f→h→m` = 4804+3556+0+1200+100 = **9660**/块；
  - merge 链 `m→n` = 4804+4804 = 9608/块；
  - AIV-MTE3 资源 `c+n` = 3556+4804 = 8360/块。
  - 故临界周期 = **9660 cyc/块**。
- **makespan = 321,836 cyc**。

### 阻塞点
1. **AIV-MTE2 被 merge 读回（4804）与 V0 gather（3556）叠加**：`m_i` 与 `a_{i+4}` 同队列 FIFO。
2. **merge 链串行**：`m_i→n_i→m_{i+1}` = 9608/块。
3. **AIV-V 尾部翻倍**：`b+f+h = 0+1200+100 = 1300`。
4. AIC-Cube（131,072）被 AIV-MTE2（262,716）完全掩盖。

## 5. 结论

**三档 HBM 带宽下的结果（详见第 7~8 节）**：

| 场景 | 不开启 | 开启 | 耗时比 | 性能比 |
|---|---|---|---|---|
| HBM 4T（题给） | 141,544 cyc | 321,836 cyc | **2.27×** | 0.44× |
| HBM 1.6T（V100） | 304,144 cyc | 801,080 cyc | **2.63×** | 0.38× |
| HBM 1.4T（V100） | 346,715 cyc | 915,538 cyc | **2.64×** | 0.38× |

**SMLA N1=128（单核 M=128 口径）：开启后耗时约为不开启的 2.27~2.64 倍，性能约为不开启的 0.38~0.44 倍。**
- 4T：不开启瓶颈 AIC-Cube（4096 cyc/块，AIV 3556 被掩盖）；开启临界环 `m→a→b→f→h→m = 9660 cyc/块`。
- 1.6T / 1.4T：V0 与 merge 均走 HBM，瓶颈转为 AIV-MTE3 资源环 `c+n`，劣化由 2.27× 恶化到 2.64×。
- 1.6T ↔ 1.4T 比值几乎不变，仅绝对耗时 ×1.14。

> 当前代码 N1=128 实际走 Split-G（`gSize>64`），每核仍 M=64，单核 pipeline 与 N64 相同，
> 代价是每 (batch, s1) 占 2 个核 + G 轴跨核规约；本节是假设不 Split-G 的口径。

## 7. V100（HBM 1.6T）带宽折算

题给数据在 HBM **4T** 环境测得；V100 环境 HBM **1.6T**，比值 **4/1.6 = 2.5×**。
HBM 读写阶段（`Q MTE2`、`KV MTE2`、`V0 MTE2`、`V0 MTE3`、`BC merge MTE2/MTE3`）×2.5；片上阶段（`Matmul`、`V1`、`V2`）不变。
N128 的 M 相关阶段（Q/Matmul/V1/V2/merge）在此之上再 ×2。

折算后各阶段 cycle：

| 阶段 | N64 4T | N128 1.6T |
|---|---|---|
| Q MTE2 | 1201 | 6004 |
| KV MTE2 | 1852 | 4630 |
| V0 MTE2 | 3556 | 8890 |
| V0 Vector | 0 | 0 |
| V0 MTE3 | 3556 | 8890 |
| Matmul1 / Matmul2 | 1024 / 1024 | 2048 / 2048 |
| V1 / V2 | 600 / 50 | 1200 / 100 |
| merge MTE2 / MTE3 | 2402 | 12010 |

结果：

| 队列 | 不开启 busy | 开启 busy |
|---|---|---|
| AIV-MTE2 | 284,480 | 656,790 |
| AIV-MTE3 | 284,480 | 668,800 |
| AIV-V | 38,400 | 41,600 |
| AIC-MTE2 | 154,164 | 154,164 |
| AIC-Cube | 131,072 | 131,072 |
| **makespan** | **304,144** | **801,080** |

- 不开启瓶颈：**AIV-MTE2 / AIV-MTE3 各 284,480**（AIC-Cube 131,072 被掩盖）。
- 开启瓶颈：**AIV-MTE3 = 32×8890 + 32×12010 = 668,800**（资源环 `c+n = 20,900/块`）。
- **开启后耗时约为不开启的 2.63 倍，性能约为不开启的 0.38 倍。**

| 指标 | 4T（原） | 1.6T（折算） |
|---|---|---|
| 不开启 | 141,544 | 304,144 |
| 开启 | 321,836 | 801,080 |
| 耗时比 | 2.27× | **2.63×** |
| 性能比 | 0.44× | **0.38×** |

## 8. V100-1.4T 带宽折算

V100 1.4T 环境，HBM 4T→1.4T，比值 **4/1.4 ≈ 2.857×**。
HBM 读写阶段（`Q MTE2`、`KV MTE2`、`V0 MTE2`、`V0 MTE3`、`BC merge MTE2/MTE3`）×2.857；片上阶段不变；N128 的 M 相关阶段再 ×2。

折算后各阶段 cycle：

| 阶段 | N64 4T | N128 1.4T |
|---|---|---|
| Q MTE2 | 1201 | 6862 |
| KV MTE2 | 1852 | 5291 |
| V0 MTE2 | 3556 | 10160 |
| V0 Vector | 0 | 0 |
| V0 MTE3 | 3556 | 10160 |
| Matmul1 / Matmul2 | 1024 / 1024 | 2048 / 2048 |
| V1 / V2 | 600 / 50 | 1200 / 100 |
| merge MTE2 / MTE3 | 2402 | 13726 |

结果：

| 队列 | 不开启 busy | 开启 busy |
|---|---|---|
| AIV-MTE2 | 325,120 | 750,626 |
| AIV-MTE3 | 325,120 | 764,352 |
| AIV-V | 38,400 | 41,600 |
| AIC-MTE2 | 176,174 | 176,174 |
| AIC-Cube | 131,072 | 131,072 |
| **makespan** | **346,715** | **915,538** |

- 不开启瓶颈：**AIV-MTE2 / AIV-MTE3 各 325,120**。
- 开启瓶颈：**AIV-MTE3 = 32×10160 + 32×13726 = 764,352**（资源环 `c+n = 23,886/块`）。
- **开启后耗时约为不开启的 2.64 倍，性能约为不开启的 0.38 倍。**

三档带宽对比：

| 指标 | 4T | 1.6T | 1.4T |
|---|---|---|---|
| 不开启 | 141,544 | 304,144 | 346,715 |
| 开启 | 321,836 | 801,080 | 915,538 |
| 耗时比 | 2.27× | 2.63× | **2.64×** |
| 性能比 | 0.44× | 0.38× | **0.38×** |

> 说明：以上为基于代码结构与题给 cycle 规格的静态/仿真估算，未在硬件上实测。
