# QSMLA `IS_BATCH_CONSISTENCY` 性能劣化分析（N1=64）

分析对象：`attention/quant_sparse_flash_mla/op_kernel/arch35`
规格：`b = 核数`、`s1 = 1`、`s2 = 4096`、`d = 512`，每核处理一个 batch 的整段 S2。
N1=64 → 每核 M=64（`s1BaseSize=64`），每 AIV 子核 `halfMRealSize=32`。
`reductionBlockSize = 128` → 32 个规约块、每块 1 个基本块、核内两两规约 31 次。

## 1. QSMLA 的 V0 dtype

QSMLA 的 KV 输入是 **fp8**（`hifloat8_t`），V0 只做 **ND2NZ cast（不改变 dtype、无 dequant、无有效 Vector 计算）**：
`CopyInKvSparse`（MTE2，读 fp8）→ `CastNd2Nz`（布局转换）→ `CopyOutKvUb2Gm`（MTE3，写 **fp8**）
（`quant_sparse_flash_mla_csa_block_vector.h:724-778`，`CopyOutKvUb2Gm` 用 `Q_T`=`hifloat8`）。
**V0 输出仍是 fp8，不是 bf16**；C1 也搬 **fp8**；Q 也是 fp8（`quant_sparse_flash_mla.cpp:62-63`）。

## 3. Pipeline 建模

| 队列 | 每 loop 发射顺序 | N64 单拍 |
|---|---|---|
| AIV-MTE2 | `a_t`(V0 load) → `m_{t-3}`(BC merge read) | 2997 / 2402 |
| AIV-MTE3 | `c_t`(V0 write) → `n_{t-3}`(BC merge write) | 2997 / 2402 |
| AIV-V | `b_t`(V0 vec) → `f_{t-2}`(V1) → `h_{t-3}`(V2) | 0 / 600 / 50 |
| AIC-MTE2 | `Q`（一次） → `d_{t-1}`(KV GM→L1) | 639 / 986 |
| AIC-Cube | `e_{t-2}`(Matmul1) → `g_{t-3}`(Matmul2) | 1024 / 1024 |

CV 依赖：`c_i→d_i`、`e_i→f_i`、`f_i→g_i`、`g_i→h_i`；BC：`h_i→m_i`、`m_i→n_i`、`n_i→m_{i+1}`。
Buffer 深度：stage0In=2, stage0Out=2, v0ResGm=3, **L1K=3**, bmm1=2, l1P=2, bmm2=1。同队列 FIFO。

## 4. 不开启

| 队列 | busy |
|---|---|
| AIV-MTE2 | **95,904** |
| AIV-MTE3 | **95,904** |
| AIV-V | 19,200 |
| AIC-MTE2 | 32,191 |
| AIC-Cube | 65,536 |

- 瓶颈：**AIV-MTE2 / AIV-MTE3 各 32×2997 = 95,904**（V0 fp8 gather 与写回）。
- **makespan = 102,959 cyc**。

## 5. 开启

| 队列 | busy |
|---|---|
| AIV-MTE2 | 170,366 |
| AIV-MTE3 | 172,768 |
| AIV-V | 20,800 |
| AIC-MTE2 | 32,191 |
| AIC-Cube | 65,536 |

- 临界环：
  ```
  m_i (2402) → a_{i+4} (2997) → b_{i+4} (0) → f_{i+2} (600) → h_{i+1} (50) → m_{i+1} (2402)
  周期 = 2402 + 2997 + 0 + 600 + 50 = 6049 cyc / 块
  ```
- **makespan = 199,926 cyc**。

### 阻塞点
1. **AIV-MTE2 被 merge 读回（2402）抢占**：`m_i` 与 `a_{i+4}`（2997）同队列 FIFO，V0 gather 被推迟。
2. **merge 链串行**：`m_i→n_i→m_{i+1}` = 4804/块。
3. **CV 同步传导**：`c_i→d_i→…→h_i→m_i` 闭环，AIC（65,536）无法掩盖。
4. QSMLA 的 V0 fp8 负载（95,904）比 SMLA bf16（113,792）小，merge 额外开销占比大，劣化更明显。

## 6. 结论

**三档 HBM 带宽下的结果（详见第 8~9 节）**：

| 场景 | 不开启 | 开启 | 耗时比 | 性能比 |
|---|---|---|---|---|
| HBM 4T（题给） | 102,959 cyc | 199,926 cyc | **1.94×** | 0.52× |
| HBM 1.6T（V100） | 252,773 cyc | 474,311 cyc | **1.88×** | 0.53× |
| HBM 1.4T（V100） | 288,468 cyc | 539,684 cyc | **1.87×** | 0.54× |

**QSMLA N1=64：开启后耗时约为不开启的 1.87~1.94 倍，性能约为不开启的 0.52~0.54 倍。**
- 4T：不开启瓶颈 AIV-MTE2/MTE3（各 2997 cyc/块）；开启临界环 `m→a→b→f→h→m = 6049 cyc/块`。
- 1.6T / 1.4T：V0 MTE3 绝对值增大后 BC 额外开销被摊薄，瓶颈为 AIV-MTE3，劣化略降。
- 1.6T ↔ 1.4T 比值几乎不变，仅绝对耗时 ×1.14。

## 8. V100（HBM 1.6T）带宽折算

题给数据在 HBM **4T** 环境测得；V100 环境 HBM **1.6T**，比值 **4/1.6 = 2.5×**。
HBM 读写阶段（`Q MTE2`、`KV MTE2`、`V0 MTE2`、`V0 MTE3`、`BC merge MTE2/MTE3`）×2.5；片上阶段（`Matmul`、`V1`、`V2`；QSMLA 无 V0 Vector）不变。

折算后各阶段 cycle：

| 阶段 | 4T | 1.6T |
|---|---|---|
| Q MTE2 | 639 | 1598 |
| KV MTE2 | 986 | 2465 |
| V0 MTE2 | 2997 | 7492 |
| V0 Vector | 0 | 0 |
| V0 MTE3 | 2997 | 7492 |
| Matmul1 / Matmul2 | 1024 / 1024 | 1024 / 1024 |
| V1 / V2 | 600 / 50 | 600 / 50 |
| merge MTE2 / MTE3 | 2402 | 6005 |

结果：

| 队列 | 不开启 busy | 开启 busy |
|---|---|---|
| AIV-MTE2 | 239,744 | 425,899 |
| AIV-MTE3 | 239,744 | 431,904 |
| AIV-V | 19,200 | 20,800 |
| AIC-MTE2 | 80,478 | 80,478 |
| AIC-Cube | 65,536 | 65,536 |
| **makespan** | **252,773** | **474,311** |

- 不开启瓶颈：**AIV-MTE2 / AIV-MTE3 各 32×7492 = 239,744**。
- 开启瓶颈：**AIV-MTE3 = 32×7492 + 32×6005 = 431,904**（资源环 `c+n = 13,497/块`）。
- **开启后耗时约为不开启的 1.88 倍，性能约为不开启的 0.53 倍。**

| 指标 | 4T（原） | 1.6T（折算） |

| 不开启 | 102,959 | 252,773 |
