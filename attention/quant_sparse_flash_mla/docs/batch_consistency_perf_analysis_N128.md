# QSMLA `IS_BATCH_CONSISTENCY` 性能劣化分析（N1=128）

分析对象：`attention/quant_sparse_flash_mla/op_kernel/arch35`
规格：`b = 核数`、`s1 = 1`、`s2 = 4096`、`d = 512`。32 个规约块、每块 1 个基本块、核内两两规约 31 次。

> 本文按 **N1=128（单核 M=128）** 推导：以 N64 为基准，把与 M 相关的阶段 ×2。
> 注意：按当前代码，`gSize>64` 走 **Split-G**，每核仍是 M=64；第 6 节说明。
> N1=64 版本见同目录 `batch_consistency_perf_analysis_N64.md`。

## 1. QSMLA 的 V0 dtype

QSMLA 的 KV 输入是 **fp8**，V0 只做 ND2NZ cast（无 dequant），**V0 输出仍是 fp8**，C1 也搬 **fp8**，Q 也是 fp8。

## 2. 各阶段 cycle（N128）

| 阶段 | 队列 | N64 | N128 |
|---|---|---|---|
| Q MTE2 | AIC-MTE2 | 639 | 1278 |
| KV MTE2（C1） | AIC-MTE2 | 986 | 986 |
| Matmul1 (QK) | AIC-Cube | 1024 | 2048 |
| Matmul2 (PV) | AIC-Cube | 1024 | 2048 |
| V0 MTE2 | AIV-MTE2 | 2997 | 2997 |
| V0 Vector | AIV-V | 0 | 0 |
| V0 MTE3 | AIV-MTE3 | 2997 | 2997 |
| V1 Vector | AIV-V | 600 | 1200 |
| V2 Vector | AIV-V | 50 | 100 |
| BC merge 读回 | AIV-MTE2 | 2402 | 4804 |
| BC merge 写回 | AIV-MTE3 | 2402 | 4804 |

## 3. 不开启

| 队列 | busy |
|---|---|
| AIV-MTE2 | 95,904 |
| AIV-MTE3 | 95,904 |
| AIV-V | 38,400 |
| AIC-MTE2 | 32,830 |
| AIC-Cube | **131,072** |

- 瓶颈：**AIC-Cube = 32×(2048+2048) = 131,072**（V0 fp8 2997 被掩盖）。
- **makespan = 139,001 cyc**。

## 4. 开启

| 队列 | busy |
|---|---|
| AIV-MTE2 | 244,828 |
| AIV-MTE3 | 249,632 |
| AIV-V | 41,600 |
| AIC-MTE2 | 32,830 |
| AIC-Cube | 131,072 |

- 临界环（取最大）：
  - merge 链 `m→n` = 4804+4804 = **9608**/块；
  - `m→a→b→f→h→m` = 4804+2997+0+1200+100 = 9101/块；
  - AIV-MTE3 资源 `c+n` = 2997+4804 = 7801/块。
  - 故临界周期 = **9608 cyc/块**。
- **makespan = 317,637 cyc**。

### 阻塞点
1. **merge 链本身串行且翻倍**：`m_i→n_i→m_{i+1}` = 9608/块，是 N128 开启后的主瓶颈。
2. **AIV-MTE2 被 `m` 抢占**：`m_i`（4804）与 `a_{i+4}`（2997）同队列 FIFO。
3. **AIV-MTE3 被 `c+n` 占据**：busy 249,632，接近临界环。
4. **CV 同步传导**：AIV 侧推迟沿 `c→d→e→f→g→h→m` 闭环传导；AIC-Cube（131,072）被完全掩盖。

## 5. 结论

**三档 HBM 带宽下的结果（详见第 7~8 节）**：

| 场景 | 不开启 | 开启 | 耗时比 | 性能比 |
|---|---|---|---|---|
| HBM 4T（题给） | 139,001 cyc | 317,637 cyc | **2.29×** | 0.44× |
| HBM 1.6T（V100） | 255,845 cyc | 794,090 cyc | **3.10×** | 0.32× |
| HBM 1.4T（V100） | 291,540 cyc | 907,553 cyc | **3.11×** | 0.32× |

**QSMLA N1=128（单核 M=128 口径）：开启后耗时约为不开启的 2.29~3.11 倍，性能约为不开启的 0.32~0.44 倍。**
- 4T：不开启瓶颈 AIC-Cube（4096 cyc/块）；开启临界环为 merge 链 `m→n`（4804+4804=9608）。
- 1.6T / 1.4T：merge 读写是 HBM 且 partial-O 翻倍，`m+n=24,020/27,452 cyc/块` 成为绝对瓶颈，劣化由 2.29× 恶化到 3.11×（三算子中最高）。
- 1.6T ↔ 1.4T 比值几乎不变，仅绝对耗时 ×1.14。

> 当前代码 N1=128 实际走 Split-G（`gSize>64`），每核仍 M=64，单核 pipeline 与 N64 相同，
> 代价是每 (batch, s1) 占 2 个核 + G 轴跨核规约；本节是假设不 Split-G 的口径。

## 7. V100（HBM 1.6T）带宽折算

题给数据在 HBM **4T** 环境测得；V100 环境 HBM **1.6T**，比值 **4/1.6 = 2.5×**。
HBM 读写阶段（`Q MTE2`、`KV MTE2`、`V0 MTE2`、`V0 MTE3`、`BC merge MTE2/MTE3`）×2.5；片上阶段（`Matmul`、`V1`、`V2`）不变。
N128 的 M 相关阶段（Q/Matmul/V1/V2/merge）在此之上再 ×2。

折算后各阶段 cycle：

| 阶段 | N64 4T | N128 1.6T |
|---|---|---|
| Q MTE2 | 639 | 3196 |
| KV MTE2 | 986 | 2465 |
| V0 MTE2 | 2997 | 7492 |
| V0 Vector | 0 | 0 |
| V0 MTE3 | 2997 | 7492 |
| Matmul1 / Matmul2 | 1024 / 1024 | 2048 / 2048 |
| V1 / V2 | 600 / 50 | 1200 / 100 |
| merge MTE2 / MTE3 | 2402 | 12010 |

结果：

| 队列 | 不开启 busy | 开启 busy |
|---|---|---|
| AIV-MTE2 | 239,744 | 612,054 |
| AIV-MTE3 | 239,744 | 624,064 |
| AIV-V | 38,400 | 41,600 |
| AIC-MTE2 | 82,076 | 82,076 |
| AIC-Cube | 131,072 | 131,072 |
| **makespan** | **255,845** | **794,090** |

- 不开启瓶颈：**AIC-Cube = 131,072**（V0 7492 被掩盖）。
- 开启瓶颈：**merge 链 `m_i→n_i→m_{i+1}` = 12010+12010 = 24,020 cyc/块**（32×24,020 = 768,640；大于 AIV-MTE3 资源环 `c+n = 19,502`）。
- **开启后耗时约为不开启的 3.10 倍，性能约为不开启的 0.32 倍。**

| 指标 | 4T（原） | 1.6T（折算） |
|---|---|---|
| 不开启 | 139,001 | 255,845 |
| 开启 | 317,637 | 794,090 |
| 耗时比 | 2.29× | **3.10×** |
| 性能比 | 0.44× | **0.32×** |

> QSMLA 的 merge 读写是 HBM，且 partial-O 在 N128 下翻倍，`m+n=24,020/块` 成为绝对瓶颈，劣化由 2.29× 恶化到 3.10×。

## 8. V100-1.4T 带宽折算

V100 1.4T 环境，HBM 4T→1.4T，比值 **4/1.4 ≈ 2.857×**。
HBM 读写阶段（`Q MTE2`、`KV MTE2`、`V0 MTE2`、`V0 MTE3`、`BC merge MTE2/MTE3`）×2.857；片上阶段不变；N128 的 M 相关阶段再 ×2。

折算后各阶段 cycle：

| 阶段 | N64 4T | N128 1.4T |
|---|---|---|
| Q MTE2 | 639 | 3652 |
| KV MTE2 | 986 | 2817 |
| V0 MTE2 | 2997 | 8563 |
| V0 Vector | 0 | 0 |
| V0 MTE3 | 2997 | 8563 |
| Matmul1 / Matmul2 | 1024 / 1024 | 2048 / 2048 |
| V1 / V2 | 600 / 50 | 1200 / 100 |
| merge MTE2 / MTE3 | 2402 | 13726 |

结果：

| 队列 | 不开启 busy | 开启 busy |
|---|---|---|
| AIV-MTE2 | 274,016 | 699,522 |
| AIV-MTE3 | 274,016 | 713,248 |
| AIV-V | 38,400 | 41,600 |
| AIC-MTE2 | 93,796 | 93,796 |
| AIC-Cube | 131,072 | 131,072 |
| **makespan** | **291,540** | **907,553** |

- 不开启瓶颈：**AIC-Cube = 131,072**（V0 8563 被掩盖）。
- 开启瓶颈：**merge 链 `m_i→n_i→m_{i+1}` = 13726+13726 = 27,452 cyc/块**（32×27,452 = 878,464；大于 AIV-MTE3 资源环 `c+n = 22,289`）。
- **开启后耗时约为不开启的 3.11 倍，性能约为不开启的 0.32 倍。**

三档带宽对比：

| 指标 | 4T | 1.6T | 1.4T |
|---|---|---|---|
| 不开启 | 139,001 | 255,845 | 291,540 |
| 开启 | 317,637 | 794,090 | 907,553 |
| 耗时比 | 2.29× | 3.10× | **3.11×** |
| 性能比 | 0.44× | 0.32× | **0.32×** |

> 说明：以上为基于代码结构与题给 cycle 规格的静态/仿真估算，未在硬件上实测。
