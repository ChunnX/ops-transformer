# SFA pytest 改造进度

基于 KVSFA 框架改造 SFA pytest，删掉量化专有参数，KV dtype 换成 float16/bfloat16。

| 文件 | 动作 | 状态 | 说明 |
|------|------|------|------|
| `sparse_flash_attention_paramset.py` | 重写 | 待改造 | 删量化参数，添加 `return_softmax_lse`，保留 `rope_head_dim` |
| `utils.py` | 重写 | 待改造 | 删除量化字段，`convert_param_combination_to_cs_format` 适配 SFA 参数 |
| `check_valid_param.py` | 重写 | 待改造 | dict 访问，删量化约束，添加 `return_softmax_lse` 校验 |

| `test_sparse_flash_attention_single.py` | 小改 | 待改造 | 调用函数名对齐 |

## 核心改动点

### 删除的量化参数
- `kv_dtype`
- `key_quant_mode`
- `value_quant_mode`
- `quant_scale_repo_mode`
- `tile_size`
- `T`、`T2`（TND query token 数）
- `key_dequant_scale`
- `value_dequant_scale`

### 新增参数
- `return_softmax_lse`（SFA 算子支持）

### 保留参数
- `rope_head_dim`（golden 计算需要）

### KV tensor 类型
- 改为 float16/bfloat16（与 query 类型相同）

### NPU 接口
- 从 `npu_kv_quant_sparse_flash_attention` 改为 `npu_sparse_flash_attention`
- 新增 `query_rope`、`key_rope` 作为单独参数传入
