## 1. 拦截点数量对比

### 1.1 总体拦截点数量

| 算子 | 拦截点数量 | 比例说明 |
|--------|------------|----------|
| **Flash Attention Score** | 158个 | 基础Flash Attention算子 |
| **Fused Infer Attention Score** | 1605个 | 融合推理算子，支持多种功能 |

### 1.2 各层拦截点分布

| 层次 | Flash Attention Score | Fused Infer Attention Score | 差异 |
|--------|-------------------|------------------------|------|
| **API层** | 123个 | 12个 | -111个 (Fused更少) |
| **InferShape层** | 20个 | 8个 | -12个 (Fused更少) |
| **Tiling层** | 15个 | 10个 | -5个 (Fused更少) |
| **Checker系统** | 0个 | 1575个 | +1575个 (Fused显著更多) |

### 1.3 拦截点差异分析

**Fused Infer Attention Score 拦截点显著更多的原因**：

1. **功能复杂度差异**
   - Flash Attention Score：单一功能，基础参数检查
   - Fused Infer Attention Score：融合推理，支持多种功能（量化、分页、RoPE、PSE等）

2. **Checker系统设计差异**
   - Flash Attention Score：无独立Checker系统，检查逻辑内嵌在Tiling层
   - Fused Infer Attention Score：独立的Checker系统，13个专用Checker模块

3. **参数数量差异**
   - Flash Attention Score：约20个主要参数
   - Fused Infer Attention Score：约50个参数（包括量化、分页、RoPE等）

### 2.1 层次结构对比

```
├─────────────────────────────────┤
```

#### Fused Infer Attention Score 层次结构

```
├─────────────────────────────────┤
│   InferShape层 (8个)        │  ← 形状推理
```

### 2.2 层次职责对比

| 层次 | Flash Attention Score | Fused Infer Attention Score | 相同点 | 不同点 |
|--------|-------------------|------------------------|--------|----------|
| **API层** | 参数预处理、版本检查、格式验证 | 参数预处理、版本检查 | 基本相同 | Fused支持更多参数类型 |

```cpp
// 代码位置：op_api/aclnn_flash_attention_score.cpp:222-277
static void SetShapeInfoForBshBsnd(int64_t alignedH1Size, FaShapeInfo &shapeInfo)
{
    if (alignedH1Size > MAX_STRIDE_S1) {
        shapeInfo.needTranspose = true;
        shapeInfo.needReshape = true;
        shapeInfo.l0InputLayoutStr = "BNSD";
        
        // B,S,N,D -> B,N,S,D
        shapeInfo.perm_in.assign({0, 2, 1, 3});
        // B,N,S,D -> B,S,N,D
        shapeInfo.perm_out.assign(shapeInfo.perm_in.cbegin(), shapeInfo.perm_in.cend());
    }
    
    if (shapeInfo.needPad) {
        shapeInfo.needReshape = true;
    }
    
    if (shapeInfo.inputLayout == InputLayout::BSND) {
        shapeInfo.needReshape = false;
    }
    
    if (shapeInfo.needReshape) {
        if (!shapeInfo.needTranspose) {
            shapeInfo.l0InputLayoutStr = "BSND";
        }
        shapeInfo.reshapedQueryShape.assign({shapeInfo.axes.b, shapeInfo.axes.s1, shapeInfo.axes.n1, shapeInfo.axes.d});
        shapeInfo.reshapedKeyShape.assign(
            {shapeInfo.axes.b, shapeInfo.axes.s2, shapeInfo.axes.n2, shapeInfo.axes.d});
        shapeInfo.reshapedValueBefore.assign({shapeInfo.axes.b, shapeInfo.axes.s2, shapeInfo.axes.n2, shapeInfo.axes.dv});
    }
}
```

   - Flash Attention Score：直接比较

   - Fused Infer Attention Score：通过布局解析隐式检查

## 结论

Flash Attention Score 和 Fused Infer Attention Score 采用了不同的拦截策略：

**Flash Attention Score**：
- 采用内嵌式拦截设计
- 拦截点相对较少（158个）
- 适合功能相对简单的场景
- 性能开销较小

**Fused Infer Attention Score**：

- 代码结构更清晰，易于维护和扩展

两种设计都有其适用场景，选择合适的拦截模式对于算子的正确性、稳定性和可维护性至关重要。
