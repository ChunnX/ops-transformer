# FlashAttentionScoreGrad (FAG) Tiling策略总结

## 1. 概述

FlashAttentionScoreGrad（FAG）是FlashAttention的反向传播算子，用于计算query、key、value的梯度（dq、dk、dv）。与前向推理相比，反向传播需要处理梯度计算的特殊性，包括多核输出的同步和重叠处理。

### 1.1 与前向推理的区别

| 特性 | 前向推理 (FA) | 反向传播 (FAG) |
|------|---------------|----------------|
| 输出 | attention输出 | dq、dk、dv三个梯度 |
| 多核同步 | 无需输出同步 | 需处理dq/dk/dv重叠 |
| 数据流 | Q→K→V→Output | Dy→Q/K/V梯度反向 |
| 确定性模式 | 无 | 需要确定性计算 |

## 6. TND变长场景处理

### 6.1 TND Layout特点

```
┌─────────────────────────────────────────────────────────────┐
│                    TND Layout说明                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  TND: (TotalTokens, NumHeads, HeadDim)                     │
│                                                             │
│  特点:                                                      │
│  - 变长序列，每个batch的seqLen不同                           │
│  - 实际长度由actualSeqQlen/actualSeqKvlen指定                │
│  - 需要动态计算每个batch的基本块数                           │
│                                                             │
│  示例:                                                      │
│  batch 0: seqQLen=128, seqKvLen=256                        │
│  batch 1: seqQLen=512, seqKvLen=1024                       │
│  batch 2: seqQLen=64,  seqKvLen=64                         │
│                                                             │
│  计算方式:                                                  │
│  ┌───────────────────────────────────────────────────────┐  │
│  │                                                       │  │
│  │  for batch b:                                         │  │
│  │    actualS1Outer[b] = ceil(actualSeqQlen[b] /         │  │
│  │                           s1CvInner)                  │  │
│  │    actualS2Outer[b] = ceil(actualSeqKvlen[b] /        │  │
│  │                           s2CvInner)                  │  │
│  │    blocksPerBatch[b] = n2 × g ×                       │  │
│  │                        actualS1Outer × actualS2Outer  │  │
│  │                                                       │  │
│  └───────────────────────────────────────────────────────┘  │
│                                                             │
│  Offset计算:                                                │
│  dqOffset = sum(actualSeqQlen[0..b-1]) × n2 × g × d        │
│           + actualS1Idx × n2 × g × d                       │
│           + n2Idx × g × d + gIdx × d                       │
│                                                             │
│  dk/dvOffset = sum(actualSeqKvlen[0..b-1]) × n2 × d        │
│              + actualS2Idx × n2 × d                        │
│              + n2Idx × d                                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 7. 确定性计算模式

### 7.1 确定性计算需求

```
┌─────────────────────────────────────────────────────────────┐
│                    确定性计算需求                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  背景:                                                      │
│  - 多核并行计算dq、dk、dv梯度                                │
│  - 同一个输出位置可能被多个核同时写入                         │
│  - 需要确保多次计算结果一致（确定性）                         │
│                                                             │
│  场景:                                                      │
│  ┌───────────────────────────────────────────────────────┐  │
│  │                                                       │  │
│  │  dq输出重叠:                                          │  │
│  │  - 同一个Q位置可能被多个S2块访问                       │  │
│  │  - 多核并行时需要原子操作或加锁                        │  │
│  │                                                       │  │
│  │  dk/dv输出重叠:                                       │  │
│  │  - 同一个K/V位置可能被多个S1块访问                     │  │
│  │  - BN2S2切分时，不同core可能计算同一个S2列             │  │
│  │                                                       │  │
│  └───────────────────────────────────────────────────────┘  │
│                                                             │
│  解决方案:                                                  │
│  1. 检测重叠位置 (JudgeIsNeedDeter)                        │
│  2. 标记需要同步的round (startNeedSyncRound)               │
```
