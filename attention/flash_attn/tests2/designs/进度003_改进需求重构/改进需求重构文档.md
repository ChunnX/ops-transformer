## 三、删除冗余参数（阶段B）

### 删除 --load-network-pt
- 删除 CLI 参数和 `orchestrator.run_case()` 的 `load_network_pt` 形参
- 删除 gen 阶段的 `if load_network_pt:` 分支（4行）
- 删除 `GenDataBase.load_network_inputs()` 方法
- 理由：导入数据形式变量太多，应由用户自己开发

### 删除 --max-retries
- 删除 CLI 参数和 `orchestrator.run_case()` 的 `max_retries` 形参
- 删除 `_do_npu` 内的 for 循环重试逻辑，NPU 异常直接抛出被外层 try/except 捕获
- ThreadPoolExecutor 保留（max_workers=1，仅为隔离执行，非重试用途）
- 理由：NPU 挂掉直接返回失败信息，不重试

### 涉及文件
`conftest.py`、`test.py`、`orchestrator.py`、`core/__init__.py`

## 七、Comparator(ABC) 基类重构（阶段E）

### 类结构

```
Comparator(ABC)                        ← 抽象基类
├── compare_two_way()                  ← CPU vs NPU 双向比对
└── compare_three_way()                ← CPU vs NPU vs GPU 三方比对

DefaultComparator(Comparator)          ← 双千分之五默认实现
├── FAIL_RATIO_LIMIT = 0.005
├── MAX_RE_RTOL = 10.0                 ← 三方：NPU max误差/GPU max误差 上限
├── AVG_RE_RTOL = 2.0                  ← 三方：NPU avg误差/GPU avg误差 上限
├── compare_two_way()                  ← 移植原 compare_outputs 逻辑
└── compare_three_way()                ← GPU 作 benchmark，NPU vs GPU 比倍数
```

### 关键设计

- **精度标准是 Comparator 子类**：DefaultComparator 提供双千分之五默认实现，算子可继承 override
- **修复数据缺口**：`_stats` 返回值补 `atol`/`rtol`（供 `precision_analyze` 读取，不再靠 fallback）
- **compare_outputs 向后兼容**：保留为模块级函数，委托给 `DefaultComparator().compare_two_way()`
- **Comparator 注入**：`run_case(comparator=...)` 参数注入（默认 DefaultComparator），算子可透传自定义 Comparator
- **三方比对**：GPU 作 benchmark，NPU 误差 vs GPU 误差比倍数（MAX_RE_RTOL=10, AVG_RE_RTOL=2），参考非量化FA的 `data_compare_benchmark_new` 核心思想，简化为 tests2 风格
- **修复 gpu_out 作用域**：try 块开头声明 `gpu_out = None`（原代码仅 if "gpu" 块内赋值，compare 阶段访问会 NameError）
- compare 阶段：`gpu_out is not None` 时走 `compare_three_way`，否则走 `compare_two_way`

### 涉及文件
`compare.py`、`orchestrator.py`
