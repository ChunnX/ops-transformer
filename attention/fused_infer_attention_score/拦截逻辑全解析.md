## 1. 整体架构

FusedInferAttentionScore 算子的拦截逻辑分为五个层次，从用户调用到最终 Kernel 执行，逐层校验和分发：

```
用户调用 aclnnFusedInferAttentionScoreV{1-5}
         │
         ▼
┌─────────────────────────────────────────┐
│  ACLNN API 层拦截                        │  ← 架构检查、版本废弃警告、预处理
└─────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────┐
│  InferShape 层拦截                       │  ← 布局验证、形状推导、类型推导
└─────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────┐
│  Tiling 层拦截                           │  ← 模板注册、参数解析、检查系统
└─────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────┐
│  Checker 系统拦截                        │  ← 数据类型、格式、功能、一致性检查
└─────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────┐
│  Kernel 层拦截 (编译期分发)              │  ← TILING_KEY + if constexpr 分发
└─────────────────────────────────────────┘
         │
         ▼
    执行计算 (Split-Fuse / MLA / GQA)
```

### 2.3 SoftmaxLse 预处理

**文件**: `op_api/aclnn_fused_infer_attention_score_inner.cpp:123-135`

当 `softmaxLseFlag == false` 时，创建占位 tensor：

```cpp
void FusedInferAttentionScoreProcessSoftmaxLse(bool softmaxLseFlag, const aclTensor *softmaxLse,
                                                const aclTensor *&tempTensor, const aclTensor *&placeHolder)
{
    if (softmaxLseFlag == false) {
        // 创建临时 tensor，地址设为 0xff
        std::vector<int64_t> shape = {0};
        int64_t addr = 0xff;
        tempTensor = aclCreateTensor(shape.data(), shape.size(), aclDataType::ACL_FLOAT,
                                     shape.data(), 0, ACL_FORMAT_ND,
                                     shape.data(), shape.size(), static_cast<void*>(&addr));
        placeHolder = tempTensor;
    } else {
        placeHolder = softmaxLse;
    }
}
```

**函数**: `InferDataTypeFusedInferAttentionScore()` (第 369-420 行)


```cpp
ge::graphStatus FiaTilingCheck::Process()
{
    // 空 Tensor 场景跳过所有检查
    if (fiaInfo_.emptyTensorFlag) {
        return ge::GRAPH_SUCCESS;
    }
    Init();
    // 四级检查链
    if (CheckSinglePara() != ge::GRAPH_SUCCESS ||
        CheckParaExistence() != ge::GRAPH_SUCCESS ||
        CheckFeature() != ge::GRAPH_SUCCESS ||
        CheckMultiParaConsistency() != ge::GRAPH_SUCCESS) {
        return ge::GRAPH_FAILED;
    }
    return ge::GRAPH_SUCCESS;
}
```

### 5.2 基础检查器

#### 数据类型支持检查

```cpp
ge::graphStatus BaseChecker::CheckDtypeSupport(const gert::CompileTimeTensorDesc *desc,
                                               const std::string &name) const
{
    const auto& it = dataMap.find(name);
    OP_CHECK_IF(it == dataMap.end(),
        OP_LOGE("FIA", "%s datatype support list should be specify in map", name.c_str()),
        return ge::GRAPH_FAILED);
    auto &expectDtypeList = it->second;
    OP_CHECK_IF(std::find(expectDtypeList.begin(), expectDtypeList.end(),
         desc->GetDataType()) == expectDtypeList.end(),
        return ge::GRAPH_FAILED);
    return ge::GRAPH_SUCCESS;
}
```

```cpp
ge::graphStatus BaseChecker::CheckFormatSupport(const gert::CompileTimeTensorDesc *desc,
                                               const std::string &name) const

                   desc->GetFormat() != ge::FORMAT_NCHW &&
```

### 7.3 关键拦截设计原则

| 原则 | 说明 | 示例 |
|------|------|------|
| **分层检查** | 将复杂检查逻辑分层，提高可维护性 | API → InferShape → Tiling → Checker → Kernel |
| **模块化** | Checker 系统采用模块化设计 | 13+ 个专用 checker 处理不同功能 |
| **防御性** | 防止无效输入导致崩溃 | 空指针检查、空 Tensor 提前返回 |
| **兼容性** | 确保硬件和软件版本兼容 | SoC 验证、架构拦截、布局验证 |
| **功能一致性** | 确保相关功能参数一致 | SparseMode 与 Mask、量化模式与 dtype |
| **提前返回** | 无效输入快速失败 | 空 Tensor 跳过所有检查、MaxWorkspace 检测 |
| **编译期分发** | 零运行时开销的模板选择 | TILING_KEY + #if + if constexpr |

### 7.4 错误处理机制

| 错误类型 | 错误码 | 处理方式 |
|----------|--------|---------|
| 运行时错误 | `ACLNN_ERR_RUNTIME_ERROR` | 架构不支持、版本废弃 |
| 内部空指针 | `ACLNN_ERR_INNER_NULLPTR` | FakeArray 创建失败 |
| 图推导失败 | `GRAPH_FAILED` | 参数校验失败 |
| 参数无效 | `ACLNN_ERR_PARAM_INVALID` | 数据类型/格式不支持 |

所有错误均通过 `OP_LOGE` / `OP_LOGW` / `OP_LOGD` 记录日志。

| 对比项 | FlashAttentionScore | FusedInferAttentionScore |
