# MQSMLA `IS_BATCH_CONSISTENCY` 性能劣化静态分析报告（N1=128）

分析对象：`attention/mixed_quant_sparse_flash_mla/op_kernel/arch35`
开关语义：由 `context_->GetDeterministicLevel() == 3` 触发（`BATCH_CONSISTENCY_LEVEL = 3`）。

> N1=64 版本见同目录 `batch_consistency_perf_analysis_N64.md`。
> 本文按 **N1=128（单核 M=128）** 推导：以 N64 为基准，把与 M 相关的阶段 ×2，其余保持不变。
> 注意：按当前代码，N1=128 实际走 **Split-G**（`gSize>64`），每核仍是 M=64；第 6 节说明两者区别。

## 1. 结论

**三档 HBM 带宽下的结果（详见第 3~8 节）**：

| 场景 | 不开启 | 开启 | 耗时比 | 性能比 |
|---|---|---|---|---|
| HBM 4T（题给） | 141,405 cyc | 320,293 cyc | **2.27×** | 0.44× |
| HBM 1.6T（V100） | 303,166 cyc | 800,102 cyc | **2.64×** | 0.38× |
| HBM 1.4T（V100） | 345,538 cyc | 914,361 cyc | **2.65×** | 0.38× |

**结论：开启后耗时约为不开启的 2.27~2.65 倍，性能约为不开启的 0.38~0.44 倍。**
- 4T：不开启瓶颈 AIC-Cube（4096 cyc/块）；开启临界环为 merge 链 `m→n`（4804+4804=9608）。
- 1.6T / 1.4T：merge 读写是 HBM，叠加 `M×2` 与 HBM 放大后，AIV-MTE3 资源环（`c+n`）成为瓶颈，劣化由 2.27× 恶化到 2.65×。
- 1.6T ↔ 1.4T 比值几乎不变，仅绝对耗时 ×1.14。

## 2. 前提与缩放

规格：`b = 核数`、`s1 = 1`、`s2 = 4096`、`d = 512`。32 个规约块、每块 1 个基本块、核内两两规约 31 次。

| 阶段 | 队列 | N64 | N128 | 是否随 M 缩放 |
|---|---|---|---|---|
| Q MTE2 | AIC-MTE2 | 1201 | **2402** | Q[M,dK]，×2 |
| KV MTE2（C1） | AIC-MTE2 | 1852 | 1852 | KV[128,dK]，无关 |
| Matmul1 (QK) | AIC-Cube | 1024 | **2048** | ×2 |
| Matmul2 (PV) | AIC-Cube | 1024 | **2048** | ×2 |
| V0 MTE2 | AIV-MTE2 | 2997 | 2997 | KV 搬入，无关 |
| V0 Vector | AIV-V | 420 | 420 | dequant，无关 |
| V0 MTE3 | AIV-MTE3 | 3556 | 3556 | KV 写回，无关 |
| V1 Vector | AIV-V | 600 | **1200** | ×2 |
| V2 Vector | AIV-V | 50 | **100** | ×2 |
| BC merge 读回 | AIV-MTE2 | 2402 | **4804** | partial-O[M,512]，×2 |
| BC merge 写回 | AIV-MTE3 | 2402 | **4804** | ×2 |

## 3. 不开启：AIC-Cube 成为瓶颈

| 队列 | busy |
|---|---|
| AIV-MTE2 | 95,904 |
| AIV-MTE3 | 113,792 |
| AIV-V | 51,840 |
| AIC-MTE2 | 61,666 |
| AIC-Cube | **131,072** |

- 临界环：**AIC-Cube 资源环 = 32×(2048+2048) → 4096 cyc/块**（AIV-MTE3 3556 被掩盖）。
- **makespan = 141,405 cyc**。

## 4. 开启：merge 链 9608 成为瓶颈

| 队列 | busy |
|---|---|
| AIV-MTE2 | 244,828 |
| AIV-MTE3 | 267,520 |
| AIV-V | 55,040 |
| AIC-MTE2 | 61,666 |
| AIC-Cube | 131,072 |

- 临界环（三者取最大）：
  - merge 链 `m_i→n_i→m_{i+1}` = 4804+4804 = **9608**/块；
  - `m→a→b→f→h→m` = 4804+2997+420+1200+100 = 9521/块；
  - AIV-MTE3 资源 `c+n` = 3556+4804 = 8360/块。
  - 故临界周期 = **9608 cyc/块**。
- **makespan = 320,293 cyc**。

### 阻塞点
1. **merge 链本身串行且翻倍**：`m_i→n_i→m_{i+1}` = 9608/块，是 N128 开启后的主瓶颈。
2. **AIV-MTE2 被 `m` 抢占**：`m_i`（4804）与 `a_{i+4}`（2997）同队列 FIFO。
3. **AIV-MTE3 被 `c+n` 占据**：busy 267,520，接近临界环。
4. **CV 同步传导**：AIV 侧推迟沿 `c→d→e→f→g→h→m` 闭环传导；AIC-Cube（131,072）被完全掩盖。

## 5. 与 N64 对比

| 指标 | N64 | N128 |
|---|---|---|
| 不开启 makespan | 122,133 | 141,405 |
| 开启 makespan | 214,426 | 320,293 |
| 耗时比（开/关） | 1.76× | **2.27×** |
| 性能比（开/关） | 0.57× | **0.44×** |
| 不开启瓶颈 | AIV-MTE3（3556/块） | AIC-Cube（4096/块） |
| 开启瓶颈 | 临界环 6469/块 | merge 链 9608/块 |

**结论**：N1 翻倍后开启 BC 的劣化由 1.76× 恶化到 2.27×：M 相关阶段翻倍使 merge 链（9608）超过 AIV 侧环（9521）成为新瓶颈。

## 6. 与当前代码实际行为的关系（Split-G）

按当前 kernel，`gSize = N1/N2 = 128 > 64`，tiling 置 `isSplitG = true`，kernel 把 G 轴对半分：
`halfG = (gSize+1)/2 = 64`，每个 AIC 处理 `gSplitSize = 64` 行
（`op_kernel/arch35/mixed_quant_sparse_flash_mla_csa_kernel.h:805-811`）。

因此**实际代码的 N1=128 是"2 个核各做 M=64"**，单核 pipeline 与 N64 文档一致；代价是：
1. 每个 (batch, s1) 占 **2 个核**（`aicCoreNum_ /= 2`）；
2. 两个 G 半区之间需要**额外的 G 轴跨核规约**；
3. 核数不足时 batch 串行化，等效于 N64 单核耗时叠加。

本文第 3~5 节的"单核 M=128"对应**假设不 Split-G、128 个头放一个核**的情形。

## 7. V100（HBM 1.6T）带宽折算

题给数据在 HBM **4T** 环境测得；V100 环境 HBM **1.6T**，比值 **4/1.6 = 2.5×**。
HBM 读写阶段（`Q MTE2`、`KV MTE2`、`V0 MTE2`、`V0 MTE3`、`BC merge MTE2/MTE3`）×2.5；片上阶段（`Matmul`、`V0 Vector`、`V1`、`V2`）不变。
N128 的 M 相关阶段（Q/Matmul/V1/V2/merge）在此之上再 ×2。

折算后各阶段 cycle：

| 阶段 | N64 4T | N128 1.6T |
|---|---|---|
| Q MTE2 | 1201 | 6004 |
| KV MTE2 | 1852 | 4630 |
| V0 MTE2 | 2997 | 7492 |
| V0 Vector | 420 | 420 |
| V0 MTE3 | 3556 | 8890 |
| Matmul1 / Matmul2 | 1024 / 1024 | 2048 / 2048 |
| V1 / V2 | 600 / 50 | 1200 / 100 |
| merge MTE2 / MTE3 | 2402 | 12010 |

结果：

| 队列 | 不开启 busy | 开启 busy |
|---|---|---|
| AIV-MTE2 | 239,744 | 612,054 |
| AIV-MTE3 | 284,480 | 668,800 |
| AIV-V | 51,840 | 55,040 |
| AIC-MTE2 | 154,164 | 154,164 |
| AIC-Cube | 131,072 | 131,072 |
| **makespan** | **303,166** | **800,102** |

- 不开启瓶颈：**AIV-MTE3 = 284,480**（AIC-Cube 131,072 被掩盖）。
- 开启瓶颈：**AIV-MTE3 资源环 `c+n = 8890+12010 = 20,900 cyc/块`**（32×20,900 = 668,800）。
- **开启后耗时约为不开启的 2.64 倍，性能约为不开启的 0.38 倍。**

| 指标 | 4T（原） | 1.6T（折算） |
|---|---|---|
| 不开启 | 141,405 | 303,166 |
| 开启 | 320,293 | 800,102 |
| 耗时比 | 2.27× | **2.64×** |
| 性能比 | 0.44× | **0.38×** |

> merge 读写本身是 HBM，叠加 M×2 与 HBM×2.5 后成为绝对瓶颈，劣化由 2.27× 恶化到 2.64×。

## 8. V100-1.4T 带宽折算

V100 1.4T 环境，HBM 4T→1.4T，比值 **4/1.4 ≈ 2.857×**。
HBM 读写阶段（`Q MTE2`、`KV MTE2`、`V0 MTE2`、`V0 MTE3`、`BC merge MTE2/MTE3`）×2.857；片上阶段不变；N128 的 M 相关阶段再 ×2。
