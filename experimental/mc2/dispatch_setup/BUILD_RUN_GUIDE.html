dispatch_min 编译运行指南

dispatch_setup（CCU 写状态位）+ dispatch_teardown（AIV aclnn 等状态位）·单 die·两条流·写/等状态位串行同步

目标平台 a6（Ascend 950PR）；本机为 a5，仅用于编译验证（a5 已实测：teardown 编译打包通过、driver 骨架链接通过）。

1. 它做什么（最小机制）

dispatch_setup（CCU）在 streamSetup 上用 LocalCopyNb 把 1 写进本卡共享状态区 statusGm（int32, slot0）。
→ 状态位 →
dispatch_teardown（AIV/aclnn）在 streamTeardown 上忙等 statusGm[0]==1，等到后写 done[0]=1 收尾。

两条流无显式 event 依赖——teardown 的忙等轮询本身就是跨流同步。状态区契约（字节级）：int32 元素、slot0、就绪值 1、按 32B 对齐分配（AIV 一次 DataCopy 搬 32B，避免越界）。LocalCopyNb 是裸字节 DMA，状态字保持 4 字节，不受 CCU Variable 8 字节规则约束。

4. 一键构建（推荐）

脚本 run.sh 用一个 TARGET 开关切换两种模式，自动定位散装 opapi 库、处理 CCU 围栏与装包：

cd /home/developer/ops-transformer/experimental/mc2/dispatch_setup

TARGET=a5 ./run.sh     # a5 骨架验证：CCU 关、不装包、直链散装 libcust_opapi.so（已实测 build OK）

7. DISPATCH_CCU_A6 开关

唯一总开关，同时控制 CCU kernel 段10 的 LocalCopyNb 真实写 与 驱动里的 CCU 拉起段。

状态cmake效果
OFF（默认）不传不编 dispatch_setup_ccu.cpp、驱动 CCU 拉起桩掉 → a5 可编可链骨架
ON-DDISPATCH_CCU_A6=ON编入 CCU kernel + 启用拉起 + 段10 真实写 → 需 a6 libhcomm（含 CCU 符号）

10. 排错 / a5↔a6 边界

编译期揪出并已修的 4 类（对抗核验看不见、只有编译器/链接器能逮）

现象根因修法
ACLNN_API / ACLNN_SUCCESS does not name a type / not declared本 CANN 版本公共 aclnn 头未导出这俩宏（只在注册内部 aclnn_util.h），对外头不自洽对外头/驱动 #ifndef 兜底定义
hccl_types.h: No such file or directoryccu_kernel.h 内部 plain #include "hccl_types.h"，缺 include 根driver include 加 ${HCOMM_INT_INC}/hccl
undefined reference to aclCreateTensor该符号在 libnnopbase；CANN 公共头根实为 x86_64-linux/include链 libnnopbase；find_path 多后缀兜底
undefined reference to HcclCcuKernel* / hcomm::CcuKernel::CcuKernela5 libhcomm 未导出 CCU 拉起符号（nm 实测为空）= a6-onlyCCU 侧整体 #ifdef DISPATCH_CCU_A6 围栏；a6 上开
本质边界：CCU kernel 继承 hcomm::CcuKernel、拉起走 HcclCcuKernel*——这些符号在 a5 libhcomm 不存在，故 CCU 路径在 a5 链接无解（编译能过）。这是硬件/库代际边界，非代码缺陷。a6 上 -DDISPATCH_CCU_A6=ON + a6 libhcomm 即解。

运行期常见（参考项目 §8 / 卡死类）

  • HCCL 建链失败（ERR02005 / store->get got 0 bytes）→ 别人占卡，跑前 §8 清场。
  • teardown 无返回/卡死 → 状态区没被写 1（CCU 没跑/状态地址不一致/cache 未刷 [T3]）；PRINTF + DumpTensor 看 statusGm 实际值。
  • aclnn 返回 561002 → 算子包未装或环境不符（先 .run --force 装包）。

本文档与 run.sh 的命令均来自 a5 实编验证（teardown EXIT=0 / driver build=0）。CCU 链接与上板运行待 a6。
