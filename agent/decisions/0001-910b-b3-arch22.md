# 0001: Default Target Is 910B B3 / ascend910b / arch22

## Status

Accepted.

## Context

用户声明当前环境是 Ascend 910B 系列 B3，系统架构是 `aarch64`。`ops-transformer` 的 `build.sh` 默认 SoC 是 `ascend910b`，顶层 CMake 将 `ascend910b` 映射到 `arch22`。

`ops-math` 当前工作树中记录了 910B3 但默认优化架构为 `arch35`。该事实属于 `ops-math` 当前环境和历史决策，不能迁移到本仓库。

## Decision

`ops-transformer` 后续默认：

- 编译目标：`--soc=ascend910b`
- 硬件语境：Ascend 910B B3
- 架构目录：`arch22`
- 系统架构：`aarch64`

## Consequences

- 优化前优先查看 `op_kernel/arch22/` 和 `ascend910b` 条件分支。
- CI 候选优先参考 `scripts/ci/ascend910b/ops_transformer_operator_list.yaml`。
- 不把 `ops-math` 的 `arch35` 默认当作 transformer 的默认优化目标。
