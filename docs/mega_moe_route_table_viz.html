推荐 group 数

groupNum = min(floor(aic / gmm1Tiles), 4)，目标是让 groupSize >= gmm1Tiles。

GMM1 tile 数

gmm1Tiles = ceil(n / 256)，单 wave 的 M 维已经固定为 256。

GMM2 tile 数

gmm2Tiles = ceil(256 / 128) * ceil(h / 256)，即 2 * ceil(h / 256)。
