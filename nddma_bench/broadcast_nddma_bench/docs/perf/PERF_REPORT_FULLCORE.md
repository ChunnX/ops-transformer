# broadcast_nddma_bench NDDMA 满核带宽报告

- **算子 / 语义类别**：broadcast_nddma_bench（广播类，5D scene AB/BA/BAB/ABA 沿广播轴复制搬运）
- **芯片 / arch**：Ascend950PR PCIE，`corenum_dim = 56`（=分核维=vector core 数，单波 per=1）
- **验证途径**：① PTA + msprof PipeUtilization（时延口径见 collection-paths.md）
- **采集**：msprof，iters=5（1 预热+5 测量，取 min），日期 2026-07-27
- **头条指标**：端到端 `db_rw` 峰值 **3037.4 GB/s**（BA_2）；纯读 `db_r` 峰值 **1769.4 GB/s**（AB_2）
- **精度前置**：ttk+kernel bitwise 全等 ✅（16/16 精度用例通过）

绝对带宽按 elemSize 线性下降。

## 2. 结论（满核）

- 满核峰值端到端带宽 **3037.4 GB/s**（BA_2），纯读 **1769.4 GB/s**（AB_2），基线 `ubloop_dim` 采集。
- SB 配置端到端峰值 3509.6 GB/s（AB_2）略高于 DB，符合广播小源大目标的缓存友好特性。
- 全部 16 例 min 时延 48~57us，稳态搬运占主导，带宽读数可复现。
