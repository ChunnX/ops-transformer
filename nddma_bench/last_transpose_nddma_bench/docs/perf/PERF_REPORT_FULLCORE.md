- **芯片 / arch**：Ascend950PR PCIE，`corenum_dim = 56`

## 2. 结论（满核）

- fp16/fp32 满核峰值端到端 **1254.5 GB/s**（L_32）、纯读 **1225.4 GB/s**（L_37）。
- int8 峰值端到端 806.9 GB/s（L_B8_2）；单字节元素带宽绝对值低于 fp16。
- 瘦高/矮胖失衡形态（如 (512,32)/(1024,16)）时延升高、带宽回落，方形 tile 带宽最优。
