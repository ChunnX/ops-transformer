# aclnnSwigluGatedMlp

## Product Support

| Product | Support |
|:--|:--:|
| Atlas A3 training/inference series | Yes |
| Atlas A2 training/inference series | Yes |

## Function

This ACLNN interface computes the fused SwiGLU gated MLP:

```text
gate_up = MatMul(x, gate_up_weight)
hidden = SwiGLU(gate_up)
y = MatMul(hidden, down_weight)
```

The `SwiGLU` stage splits `gate_up` into two equal parts on the last dimension
and applies `silu(left) * right`.

## Function Prototype

Every ACLNN operator uses a two-step interface. Call
`aclnnSwigluGatedMlpGetWorkspaceSize` first to validate parameters, build the
executor, and get the workspace size. Then call `aclnnSwigluGatedMlp` to launch
the executor.

```cpp
aclnnStatus aclnnSwigluGatedMlpGetWorkspaceSize(
    const aclTensor *x,
    const aclTensor *gateUpWeight,
    const aclTensor *downWeight,
    int64_t cubeMathType,
    aclTensor *y,
    uint64_t *workspaceSize,
    aclOpExecutor **executor);
```

```cpp
aclnnStatus aclnnSwigluGatedMlp(
    void *workspace,
    uint64_t workspaceSize,
    aclOpExecutor *executor,
    aclrtStream stream);
```

## aclnnSwigluGatedMlpGetWorkspaceSize

| Name | Input/Output | Description | Data Type | Format | Shape |
|:--|:--|:--|:--|:--|:--|
| x | Input | MLP input tensor. | BFLOAT16, FLOAT16, FLOAT | ND | `[..., hidden_size]`, rank >= 2 |
| gateUpWeight | Input | First matmul weight. | BFLOAT16, FLOAT16, FLOAT | ND | `[hidden_size, 2 * intermediate_size]` |
| downWeight | Input | Second matmul weight. | BFLOAT16, FLOAT16, FLOAT | ND | `[intermediate_size, out_size]` |
| cubeMathType | Input | MatMul compute mode. Valid values are `0` and `1`. | int64 | - | - |
| y | Output | Output tensor. | BFLOAT16, FLOAT16, FLOAT | ND | `[..., out_size]` |
| workspaceSize | Output | Device workspace size required by the executor. | uint64_t | - | - |
| executor | Output | ACLNN executor generated by the first-stage interface. | aclOpExecutor* | - | - |

### Return Value

Returns `ACLNN_SUCCESS` on success. Returns a parameter error when a null pointer,
unsupported data type, mismatched data type, invalid shape, or invalid
`cubeMathType` is supplied.

## aclnnSwigluGatedMlp

| Name | Input/Output | Description |
|:--|:--|:--|
| workspace | Input | Device workspace address. |
| workspaceSize | Input | Workspace size returned by `aclnnSwigluGatedMlpGetWorkspaceSize`. |
| executor | Input | Executor returned by `aclnnSwigluGatedMlpGetWorkspaceSize`. |
| stream | Input | ACL runtime stream used to launch the task. |

### Return Value

Returns `ACLNN_SUCCESS` on successful launch.

## Constraints

- `x`, `gateUpWeight`, `downWeight`, and `y` must not be null.
- `x`, `gateUpWeight`, `downWeight`, and `y` must use the same data type.
- `gateUpWeight` and `downWeight` must be 2D.
- `gateUpWeight.shape[0]` must equal `x.shape[-1]`.
- `gateUpWeight.shape[1]` must be positive and divisible by 2.
- `downWeight.shape[0]` must equal `gateUpWeight.shape[1] / 2`.
- `y.shape[:-1]` must equal `x.shape[:-1]`, and `y.shape[-1]` must equal `downWeight.shape[1]`.
