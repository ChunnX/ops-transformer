# 自验证步骤说明

完整复现步骤与原始材料见本机交付目录（或随验收材料一并提交的 `验收交付件/`）：

- `验收交付件/02_自测用例及测试代码.md`
- `验收交付件/02_自测用例清单_精度.csv` / `02_自测用例清单_性能.csv`
- `验收交付件/03_自测报告.md` / `03_自测报告.xlsx`
- `验收交付件/logs/`、`验收交付件/figures/`
- `验收交付件/task_submission_xlsx/`（精度/性能/内存正式 xlsx，仓外交付）

本目录为任务书规定的私仓 `task_submission`（ops-transformer 根目录）。

> 说明：仓库 OAT 合规禁止提交二进制（xlsx），正式报表 xlsx 放在验收交付件中提交；本目录仅保留文本日志与步骤说明。

| 文件 | 说明 |
|------|------|
