# kv_cache_turbo_quant 自验证步骤说明

## 1. 环境信息

| 项目 | 配置 |
| --- | --- |
| 硬件 | Atlas 800T A2（Ascend 910B1，8 卡，单卡 64GB HBM） |
| CANN | 9.2.0-beta.1（满足任务书 CANN 9.1.0+ 要求） |
| 驱动固件 | 26.0.rc1 |
| 测试设备 | 单卡（ASCEND_RT_VISIBLE_DEVICES 指定空闲卡） |
| 代码仓 | https://gitcode.com/weixin_53562472/ops-transformer ，分支 `feature/kv_cache_turbo_quant_a2`，算子目录 `experimental/attention/kv_cache_turbo_quant` |

## 2. 编译算子

```bash
source /usr/local/Ascend/ascend-toolkit/set_env.sh
cd <ops-transformer 仓根目录>
bash build.sh --pkg --experimental --soc=ascend910b --ops=kv_cache_turbo_quant -j16
# 产物：build_out/cann-ops-transformer-custom_linux-aarch64.run
./build_out/cann-ops-transformer-custom_linux-aarch64.run --quiet --install-path=<install_dir>
# 运行前环境：
source /usr/local/Ascend/ascend-toolkit/set_env.sh
export ASCEND_CUSTOM_OPP_PATH=<install_dir>/vendors/custom_transformer
export LD_LIBRARY_PATH=<ops-transformer 仓>/build:$LD_LIBRARY_PATH   # 仓内构建的 libopapi_math.so 所在目录
```

## 3. 生成自测数据与 golden

```bash
python3 tests/gen_test_data.py --out /data/ma-user/work/ASCEND_DEVELOP/test_data
```

- 覆盖任务书 3.5 节全部 5 个自测 case（gqa_decode_b1 / gqa_decode_b64 / gqa_prefill_t2048 / gqa_mse2_t2048 / gqa_mse4_t2048）。
- golden 为任务随附 `golden.py:calc_expect_func` 的 CPU torch 移植（fp32 数学完全一致，含 `_pack_bits` 打包序、Lloyd-Max 质心、clamp_min(1e-30) 零向量语义），生成输入 `.bin` 与期望输出 `.bin`。

## 4. 编译并运行 aclnn 自测程序

```bash
# 编译（aclnn 头文件与库来自第 2 步安装的自定义算子包 + toolkit）
A=/usr/local/Ascend/ascend-toolkit/latest
C=/usr/local/Ascend/cann-9.2.0-beta.1
V=<install_dir>/vendors/custom_transformer
g++ -O2 -std=c++17 -o test_aclnn_kv_cache_turbo_quant \
    experimental/attention/kv_cache_turbo_quant/examples/test_aclnn_kv_cache_turbo_quant.cpp \
    -I$A/include -I$V/op_api/include \
    -L$A/lib64 -L$V/op_api/lib -L$C/aarch64-linux/lib64 \
    -Wl,-rpath-link,$C/aarch64-linux/lib64 -Wl,-rpath-link,$A/lib64 \
    -lascendcl -lcust_opapi -lnnopbase

# 精度测试（5 个 case 逐一比对，输出 mismatch 计数）+ 性能测试（迭代取平均）
ASCEND_RT_VISIBLE_DEVICES=6 ./test_aclnn_kv_cache_turbo_quant /data/ma-user/work/ASCEND_DEVELOP/test_data 500
# KVTQ_DUMP=1 可额外落盘算子输出用于离线比对
```

- **精度测试 case**：上述 5 个任务 case 全量；判定标准：`quant_idx` 字节失配率 ≤ 1e-5、`quant_qjl` 字节失配率 ≤ 1.1e-5（case.json err_threshold），bf16 `quant_norm/quant_gamma` 失配率 ≤ 1e-3（仅 fp32 累加顺序噪声）。
- **性能测试 case**：同样 5 个；判定标准：相对任务书给出的 PyTorch eager 基线（1491.676 / 1552.784 / 3855.422 / 3607.963 / 5286.502 us）加速 ≥ 10×。
- host 侧 UT（infershape/tiling gtest）：`bash build.sh --ophost --experimental --soc=ascend910b --ops=kv_cache_turbo_quant -j`（tests/ut/op_host 下 11 个用例）。
