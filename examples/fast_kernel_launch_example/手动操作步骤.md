# 头开销测试 - 手动操作步骤

> 先设置 GitCode token 环境变量:
> ```bash
> export GITCODE_TOKEN=<your_gitcode_access_token>
> ```

## 1. 获取 PR 代码

```bash
git clone https://gitcode.com/cann/ops-transformer.git
cd ops-transformer
git fetch https://gitcode.com/cann/ops-transformer.git +refs/merge-requests/10421/head:pr_10421
git checkout pr_10421
cd examples/fast_kernel_launch_example
```

## 2. Source CANN 环境

```bash
source <CANN安装路径>/set_env.sh
```

## 3. 一键执行

```bash
bash run_head_overhead.sh
```

自动完成：检测环境 → sed 改核数构建满核 wheel → msprof capture 采集 add+gmm 两组头开销数据 → 汇总输出 `head_overhead_results/summary.csv`。

## 4. 查看结果

```bash
cat head_overhead_results/summary.csv
```

输出示例：

```
算子,类型,核数,稳态mean(us)
add,Vector,56,1.754
grouped_matmul,Cube,28,2.561
```

## 5. 分步骤手动执行

如需分步执行（调试或自定义参数），按以下步骤操作。

### 5.1 安装依赖

```bash
pip install -r requirements.txt
```

### 5.2 修改核数（sed 改满核）

A5（ascend950）: Vector=56, Cube=28
A3（ascend910_93）: Vector=48, Cube=24

```bash
# add: numBlocks 改为满核
sed -i 's/int64_t numBlocks = std::min(coreNum, (totalLength + MIN_ELEMS_PER_CORE - 1) \/ MIN_ELEMS_PER_CORE);/int64_t numBlocks = 56;/' csrc/add/ascend950/add.cpp
# add: launch 核数也要改
sed -i 's/<<<[0-9]*,/<<<56,/g' csrc/add/ascend950/add.cpp
# gmm: blockDim 改为满核
sed -i 's/uint32_t blockDim = tilingData.gmmBaseParams.get_coreNum();/uint32_t blockDim = 28; tilingData.gmmBaseParams.coreNum = 28;/' csrc/grouped_matmul/ascend950/grouped_matmul.cpp
```

> 确认修改: `grep 'numBlocks = ' csrc/add/ascend950/add.cpp` 和 `grep '<<<' csrc/add/ascend950/add.cpp`

### 5.3 构建 Wheel

```bash
export NPU_SOC_VERSION=ascend950
python3 setup.py clean
python3 -m build --wheel --no-isolation
python3 -m pip install dist/*.whl --force-reinstall --no-deps
```

### 5.4 采集 add 头开销

```bash
OP_TYPE=add msprof --output=/tmp/msprof_add python3 scan_replay.py
```

### 5.5 采集 grouped_matmul 头开销

```bash
OP_TYPE=gemm msprof --output=/tmp/msprof_gmm python3 scan_replay.py
```

### 5.6 查看结果

```bash
# add
find /tmp/msprof_add -name "op_summary_*.csv" -exec python3 -c "
import csv, statistics, sys
with open(sys.argv[1]) as f:
    rows = list(csv.DictReader(f))
kr = [r for r in rows if 'add_kernel' in r.get('Op Name','')]
durs = [float(r['Task Duration(us)'].strip().rstrip(chr(9))) for r in kr[2:]]
print(f'add steady mean={statistics.mean(durs):.3f}us  n={len(durs)}')
" {} \;

# grouped_matmul
find /tmp/msprof_gmm -name "op_summary_*.csv" -exec python3 -c "
import csv, statistics, sys
with open(sys.argv[1]) as f:
    rows = list(csv.DictReader(f))
kr = [r for r in rows if 'groupedmatmul' in r.get('Op Name','')]
durs = [float(r['Task Duration(us)'].strip().rstrip(chr(9))) for r in kr[2:]]
print(f'gmm steady mean={statistics.mean(durs):.3f}us  n={len(durs)}')
" {} \;
```

