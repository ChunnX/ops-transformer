# 头开销测试 - 手动操作步骤

## 1. Clone 仓库

```bash
git clone -b head-overhead-clean https://gitcode.com/cann/ops-transformer.git
cd ops-transformer/examples/fast_kernel_launch_example
```

## 2. Source CANN 环境

```bash
source <CANN安装路径>/set_env.sh
```

## 3. 一键执行

```bash
bash run_head_overhead.sh
```

自动完成：检测环境 → sed 改核数构建满核 wheel → msprof capture 采集 add+gmm 两组头开销数据 → 汇总输出 `head_overhead_results/summary.csv`。

## 4. 查看结果

```bash
cat head_overhead_results/summary.csv
```

输出示例：

```
算子,类型,核数,稳态mean(us)
add,Vector,56,3.172
grouped_matmul,Cube,28,2.559
```
