═══════════ 第 2 步：新增 prep_cache.py（独立模块） ═══════════
文件：examples/mc2/engram_test/prep_cache.py
硬性约束：只允许 import 标准库 + numpy + torch；严禁 import torch_npu / cann_ops_transformer /
psutil（保证无 NPU 机器可运行与被 bench_prep 复用）。模块导入零副作用。

核心设计（务必逐条落实）：
1. GEN_VERSION = 1（生成算法变化时递增，旧缓存自动失效）。
2. cache_key(total, hidden, dtype_name, use_fp8, sf_dtype_name, seed) → sha1 十六进制；
   键要素：总行数/hidden/dtype/use_fp8/sf_dtype/seed/GEN_VERSION——注意 fetch_mode 不参与（local/sliced 配对复用）。
3. 目录布局：{cache_dir}/{key}.storage.bin、{key}.sf.bin（use_fp8=0 时不存在）、{key}.meta.json。
   meta.json 字段：total/hidden/dtype/use_fp8/sf_dtype/seed/gen_version/pattern/created/host/elapsed_s/workers。
4. generate(cache_dir, total, hidden, dtype, use_fp8, sf_dtype, seed, pattern="random",
           num_workers=None, block_rows=8192, val_min=None, val_max=None) -> dict：
   - 命中判定：三文件齐全（sf 按需）且 meta 全字段匹配 → 返回 {"cache_hit": True, "key":..., "path":...}，不重生成。
   - 未命中：np.memmap(mode="w+", shape=(total, hidden), dtype=存储宽度) 直接按最终 dtype 字节落盘
     （fp8 系按 uint1 宽度即 "|u1" 落盘；bf16/fp16 按 "|u2"；fp32 "|u4"；int 按 np 对应宽度）。
   - 生成前先把行空间切成固定 block_rows 的块（块 i 覆盖 [i*block_rows, min((i+1)*block_rows, total))），
     再把块按 round-robin 分给 worker 进程（mp.get_context("fork").Pool）。
   - 【确定性关键】每块的 rng = np.random.default_rng(np.random.SeedSequence(entropy=seed,
     spawn_key=(kind_id, block_idx)))，kind_id：storage=0、sf=1。数据只依赖 (seed, kind, block_idx)，
     与 worker 数无关 → 任意机器任意并行度生成结果逐字节一致（bench 抽样校验依赖此性质）。
   - worker 内部逐块生成小块临时数组（fp32 ≈ block_rows×hidden×4B ≈ 18MB 常驻缓存）后立即转换写入
     memmap 切片，禁止整表 fp32、禁止 clone、禁止 /dev/shm：
     · 浮点 dtype（fp8_e4m3fn/fp8_e5m2/bf16/fp16/fp32）：rng.standard_normal((br,hidden),dtype=np.float32)
       → torch.from_numpy(...).to(torch dtype).numpy() → 写入（有 val_min/val_max 时改用 rng.random 线性缩放）。
     · int dtype：rng.integers(low, high, (br,hidden), dtype=...) 直写。
     · pattern="arange"：确定性行号派生模式（如 (row_idx*2654435761 + col_idx) 混合后截断到 dtype 宽度），
       不用 rng，近零成本，供冒烟。
   - sf 表（use_fp8=1）：shape=(total, ceil(hidden/32))；e8m0：rng.random 块→fp32 位运算
     (bits>>23)&0xFF → uint8 写入；sf_dtype=float32：fp32 直写。
   - 每 worker 打开自己的 np.memmap(mode="r+")；主进程完成后 mm.flush()。
   - num_workers 默认 min(32, os.cpu_count()//2)。
   - 结束写 meta.json（含耗时）并返回 {"cache_hit": False, "elapsed_s":..., "key":...}。
5. load(cache_dir, total, hidden, dtype, use_fp8, sf_dtype, seed, pattern="random") ->
   (storage_tensor, sf_tensor|None)：np.memmap(mode="r") → torch.from_numpy → fp8 系 .view(torch dtype)；
   返回的是 memmap 视图张量（零拷贝，不 clone）；meta 不匹配/缺失时抛 RuntimeError（含 key 与期望 meta）。
6. drop_page_cache(tensor)：基于 numpy memmap 的 offset/长度用 ctypes 调 madvise(MADV_DONTNEED)，
   任何异常打 WARNING 后忽略（可选开关用）。
7. purge(cache_dir, keys=None)：删除全部或指定 key 的缓存文件。
8. 模块自带 `python prep_cache.py --selftest` 自测：生成 (4096, 576) fp8+e8m0 → load → 抽样 3 块重算比对
   逐字节一致 → 删除缓存 → 打印 "SELFTEST PASS"。
