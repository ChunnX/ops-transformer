# 整数安全转换：NaN/空串/nan/none/纯空格按0处理，其余强转int，非法值报明确错误
def to_int(col, x):
    try:
        if pd.isna(x):
            return 0
        s = str(x).strip()
        if s == "" or s.lower() in ("nan", "none"):
            return 0
        return int(float(x))
    except Exception:
        raise ValueError(f"[ERROR] 列 {col} 存在非法整数值: {x!r}")
